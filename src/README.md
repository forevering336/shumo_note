---

## 这本笔记是什么

这是一本以**手册体**编写的团队学习笔记。它不同于课堂笔记或博客文章，其设计目标是：

- **结构化检索** — 像查字典一样快速定位某个模型或方法
- **可累积更新** — 学一点记一点，版本迭代，而非一次性成稿
- **锻炼能力** — 在整理知识点的同时将其内化于心
