# 前言

## 为什么要写这本笔记

这本笔记主要的作用是作为我们小组的学习笔记，我们小组一致认为国赛第一阶段的培训的主要不在精准掌握每个数学建模背后的复杂原理，而是通过较为粗略的课外浏览和线上线下的系统培训对**数模竞赛的大致流程，解题思路，一些注意事项**有清晰的认知。

这本笔记的目的，就是把**学过的内容内化成自己的东西**，并以一种可以快速检索、持续累积的形式沉淀下来。

## 更新约定

- 每完成一个知识点的学习，增补到对应章
- 每次重大修改在 `README.md` 的版本记录中留痕
- 源文件为 Markdown，使用 Git 管理版本
