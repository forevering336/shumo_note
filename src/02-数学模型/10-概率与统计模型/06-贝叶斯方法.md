# 10.6 贝叶斯方法

**贝叶斯**把未知参数看作随机变量，用**先验**与**似然**更新得到**后验**，天然适合小样本、需要概率表述参数可信程度的场景。

---

## 一、核心公式

$$
\pi(\theta\mid x) = \frac{f(x\mid\theta)\,\pi(\theta)}{\int f(x\mid\theta)\,\pi(\theta)\,d\theta}
\propto \underbrace{f(x\mid\theta)}_{\text{似然}} \cdot \underbrace{\pi(\theta)}_{\text{先验}}
$$

| 概念 | 含义 |
|------|------|
| 先验 $\pi(\theta)$ | 见到数据前对 $\theta$ 的信念 |
| 似然 $f(x\mid\theta)$ | 数据模型 |
| 后验 $\pi(\theta\mid x)$ | 更新后的信念 |
| 后验均值 / MAP | 点估计两种常用选择 |
| 可信区间 | 后验概率质量为 $1-\alpha$ 的区间 |

与频率置信区间哲学不同：贝叶斯直接说“$\theta$ 落在区间内的后验概率是 95%”。

后验结论以所选先验和似然为条件，因此“概率是 95%”并不是脱离模型假设的客观保证。先验来源与似然合理性必须交代清楚。

---

## 二、共轭先验（可手算）

| 似然 | 共轭先验 | 后验 |
|------|----------|------|
| 二项 / 伯努利 | Beta | Beta |
| 泊松 | Gamma | Gamma |
| 正态均值（方差已知） | 正态 | 正态 |
| 多项 | Dirichlet | Dirichlet |

**例子：** 命中率 $\theta$，先验 $\mathrm{Beta}(\alpha,\beta)$，命中 $s$ 次、出手 $n$ 次，后验 $\mathrm{Beta}(\alpha+s,\beta+n-s)$。  
后验均值 $\frac{\alpha+s}{\alpha+\beta+n}$，可看成先验虚拟样本与数据的折中。

例如先验为 $\mathrm{Beta}(2,2)$，观察到 10 次中命中 7 次，则后验为 $\mathrm{Beta}(9,5)$，后验均值为 $9/14\approx0.643$。它比样本命中率 0.7 略向先验均值 0.5 收缩。

---

## 三、贝叶斯决策与分类

- **后验风险最小** → 决策规则  
- 朴素贝叶斯分类：特征条件独立  

$$
\hat c = \arg\max_c P(c)\prod_j P(x_j\mid c)
$$

实现简单，文本分类、赛题基线常用（`sklearn.naive_bayes`）。

---

## 四、计算：从共轭到 MCMC

- 共轭：解析更新  
- 一般模型：MCMC、变分推断  
- 工具：PyMC、Stan；赛题中若无必要，不必上复杂 MCMC  

经验贝叶斯：从数据估计先验超参数，再做贝叶斯更新。

使用 MCMC 时至少检查多条链是否混合、$\hat R$ 是否接近 1、有效样本量是否足够，并查看轨迹图。采样“跑完”不代表已经正确逼近后验。

---

## 五、与经典方法对比

| | 频率派 | 贝叶斯 |
|--|--------|--------|
| 参数 | 固定未知常数 | 随机变量 |
| 区间 | 置信区间 | 可信区间 |
| 小样本 | 可能不稳 | 先验可提供正则 |
| 计算 | 常有解析/渐近 | 后验积分可能难 |

数模选择建议：

- 需要融入专家信息、层次结构 → 贝叶斯  
- 常规估计检验够用 → 频率派更省事  
- 分类基线 → 朴素贝叶斯  

---

## 六、写作提示

1. 明确写出先验及理由（无信息 / 共轭 / 文献）  
2. 报告后验摘要：均值、标准差、可信区间  
3. 做先验灵敏度：换先验后结论是否稳健  
4. 做后验预测检验：从后验生成模拟数据，与真实数据的关键统计量比较
5. 区分后验可信区间与未来观测的后验预测区间

---

## 七、何时值得使用贝叶斯

| 情形 | 价值 |
|------|------|
| 有可靠历史数据或专家信息 | 可通过先验正式融入模型 |
| 分层数据、不同地区样本量悬殊 | 部分汇聚能稳定小样本估计 |
| 需要参数或决策的完整概率分布 | 可直接传播不确定性 |
| 只需常规大样本点估计 | 频率方法通常更简洁 |

先验不能凭“贝叶斯需要先验”而随意指定。若缺少可靠知识，可选弱信息先验并做灵敏度分析。

---

## 小结

贝叶斯方法的核心是用似然把先验更新为后验。简单共轭模型可以手算；模型复杂后再考虑 MCMC 或变分推断，并把采样诊断和先验敏感性一同报告。
