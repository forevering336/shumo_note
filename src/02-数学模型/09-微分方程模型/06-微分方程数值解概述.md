# 9.6 微分方程数值解概述

实际模型中的 ODE/PDE 往往没有方便的解析解，因此最后通常要落到数值计算。除了会调用求解器，还要知道容差、步长和刚性会怎样影响结果。

---

## 一、初值问题标准形式

$$
\mathbf{y}' = \mathbf{f}(t,\mathbf{y}), \quad \mathbf{y}(t_0)=\mathbf{y}_0
$$

目标：在离散时刻得到 $\mathbf{y}_n \approx \mathbf{y}(t_n)$。

---

## 二、常用 ODE 方法

### 1. 欧拉法

$$
y_{n+1} = y_n + h f(t_n, y_n)
$$

一阶精度，简单但粗糙。

### 2. 经典四阶龙格–库塔（RK4）

$$
\begin{aligned}
k_1 &= f(t_n,y_n) \\
k_2 &= f(t_n+\tfrac{h}{2}, y_n+\tfrac{h}{2}k_1) \\
k_3 &= f(t_n+\tfrac{h}{2}, y_n+\tfrac{h}{2}k_2) \\
k_4 &= f(t_n+h, y_n+h k_3) \\
y_{n+1} &= y_n + \frac{h}{6}(k_1+2k_2+2k_3+k_4)
\end{aligned}
$$

全局误差为 $O(h^4)$，手写模拟常用；这不代表固定步长 RK4 对刚性问题也合适。

### 3. 自适应与刚性

- **自适应 RK**（如 Dormand–Prince）：`solve_ivp` 默认 `RK45`  
- **刚性**（快慢尺度并存）：改用隐式 `BDF`、`Radau`  

---

## 三、Python / MATLAB 速查

**Python：**

```python
from scipy.integrate import solve_ivp

def f(t, y):
    beta, gamma = 0.3, 0.1
    S, I, R = y
    N = S + I + R
    return [-beta*S*I/N, beta*S*I/N - gamma*I, gamma*I]

t_eval = range(161)
sol = solve_ivp(
    f, [0, 160], [990, 10, 0], t_eval=t_eval,
    rtol=1e-6, atol=1e-8, method="RK45"
)

if not sol.success:
    raise RuntimeError(sol.message)
```

`t_eval` 指定需要输出的时间点，但不等于求解器内部步长。刚性问题可用 `method="BDF"` 或 `"Radau"`；存在突变、碰撞或达到阈值即停止时，可使用 `events` 事件函数。

**MATLAB：** `ode45`；刚性用 `ode15s`。

---

## 四、误差与实践建议

| 概念 | 说明 |
|------|------|
| 容差 `rtol/atol` | 自适应方法的精度控制 |
| 守恒检验 | 总人数、总能量是否近似不变 |
| 步长/容差加密对比 | 两次结果接近则较可信 |
| 求解器状态 | 检查 `sol.success` 与失败信息 |

求解后要查看是否出现负人口、负浓度等不合理值，也要比较更严格容差下的曲线。若容差略有改变就导致长期趋势完全不同，应先排查刚性、步长和模型本身的敏感性。

---

## 五、边值与 PDE 数值（简述）

- **两点边值**：射击法或差分 + 方程组  
- **两点边值工具**：Python `scipy.integrate.solve_bvp`
- **PDE**：有限差分 / 线法（空间离散 → ODE 组）；MATLAB `pdepe`  

---

## 六、参数估计 + 数值解闭环

```
猜测 θ → solve_ivp 得 ŷ(t;θ) → 与数据比残差
    → 优化器更新 θ → 直至残差足够小
```

残差对 $\theta$ 可能非凸，需合理初值或多起点。

参数拟合时应让求解器在观测时刻输出结果，并根据测量误差选择损失函数。若某些状态没有被直接观测，需说明它们如何通过模型间接辨识；必要时报告参数置信区间或 bootstrap 结果。

---

## 小结

| 场景 | 推荐 |
|------|------|
| 一般非刚性 IVP | `solve_ivp` RK45 / `ode45` |
| 刚性 | BDF / `ode15s` |
| 理解算法 | 手写 Euler / RK4 |

数值解 = **方法选择 + 精度控制 + 合理性检验**。与稳定性分析结合，才能完整回答模型表现。
