# 9.5 稳定性分析

求出解析解往往很难，但**平衡点是否稳定、解长期往哪走**却常能判断。稳定性分析是微分方程建模的定性核心。

- **稳定**：初值受到小扰动后，轨迹始终留在平衡点附近；
- **渐近稳定**：不仅留在附近，而且最终回到平衡点；
- **全局稳定**：从给定状态域内任意允许初值出发都趋于该平衡点。

线性化通常只能给出**局部**结论，不能直接宣称全局稳定。

---

## 一、平衡点

对自治系统 $\mathbf{y}'=\mathbf{f}(\mathbf{y})$，平衡点 $\mathbf{y}^*$ 满足：

$$
\mathbf{f}(\mathbf{y}^*) = \mathbf{0}
$$

---

## 二、一维稳定性

$y'=f(y)$，在 $y^*$ 处看 $f'(y^*)$：

| $f'(y^*)$ | 结论 |
|-----------|------|
| $<0$ | 渐近稳定（吸引） |
| $>0$ | 不稳定（排斥） |
| $=0$ | 临界，看高阶项或相线图 |

**例子**：Logistic $f(N)=rN(1-N/K)$  

- $N^*=0$：$f'(0)=r>0$ → 不稳定  
- $N^*=K$：$f'(K)=-r<0$ → 稳定  

---

## 三、二维线性系统

$$
\mathbf{y}' = A \mathbf{y}
$$

由特征值分类；也可用 $\tau=\mathrm{tr}(A)$，$\Delta=\det(A)$：

| 条件 | 类型 |
|------|------|
| $\Delta<0$ | 鞍点（不稳定） |
| $\Delta>0$ 且 $\tau<0$ | 稳定（结点或焦点） |
| $\Delta>0$ 且 $\tau>0$ | 不稳定 |
| $\tau=0,\Delta>0$ | 中心（线性意义下） |

当 $\Delta>0$ 时，还可用判别式 $\tau^2-4\Delta$ 区分结点（非负）与焦点（负）。真正决定渐近稳定的是所有特征值的实部均小于 0。

---

## 四、非线性系统的局部线性化

Jacobian $J = D\mathbf{f}(\mathbf{y}^*)$。若所有特征值实部均不为 0（双曲平衡点），则局部性态与线性系统 $\mathbf{z}'=J\mathbf{z}$ 一致。若存在实部为 0 的特征值，线性化无法给出完整结论，需要高阶项、Lyapunov 函数或中心流形等工具。

---

## 五、阈值与分支

- **阈值**：参数跨过某值时性态突变，如 SIR 中 $R_0=1$  
- **分支**：平衡点个数或稳定性随参数变化（跨临界、Hopf 等）  

论文中可画 $R_0$ 与最终规模关系，或简单分岔示意。

---

## 六、推荐操作流程

1. 令导数为 0，求全部平衡点  
2. 算 Jacobian，代入各平衡点  
3. 看特征值实部 / 迹与行列式  
4. 结合参数讨论（如 $R_0>1$ 与否）  
5. 用数值积分验证时间序列或相图  

```python
import numpy as np

J = np.array([[-1.0, 2.0], [-3.0, -4.0]])
eigvals = np.linalg.eigvals(J)
is_locally_asymptotically_stable = np.all(np.real(eigvals) < 0)
print(eigvals, is_locally_asymptotically_stable)
```

论文中应同时给出平衡点的实际含义。例如“无病平衡点稳定”比只写“特征值为负”更有解释力；参数阈值则应联系可操作措施，如降低接触率或提高恢复率。

---

## 小结

稳定性回答：**长期是趋于平衡、发散，还是振荡？** 一维看 $f'$，二维看迹与行列式，高维看 Jacobian 特征值。与数值解结合，构成完整分析。
