# 9.1 微分方程基础概念

**微分方程**（Differential Equation）是联系未知函数与其导数（或偏导数）的方程。当系统的变化率依赖于当前状态时——人口增长、传染病传播、冷却、振动、扩散等——微分方程是最自然的建模语言。

---

## 基本术语

| 术语 | 含义 |
|------|------|
| **常微分方程 ODE** | 未知函数只依赖一个自变量（通常是时间 $t$） |
| **偏微分方程 PDE** | 未知函数依赖多个自变量（如 $x,t$ 或 $x,y$） |
| **阶** | 方程中出现的最高阶导数的阶数 |
| **线性 / 非线性** | 未知函数及其导数是否只以一次式出现 |
| **初值问题 IVP** | 方程 + 初始时刻的状态 |
| **边值问题 BVP** | 方程 + 边界上的条件 |

一般 $n$ 阶 ODE 可写为：

$$
F\big(t, y, y', y'', \ldots, y^{(n)}\big) = 0
$$

常化为**一阶方程组**：

$$
\mathbf{y}' = \mathbf{f}(t, \mathbf{y}), \quad \mathbf{y}(t_0) = \mathbf{y}_0
$$

---

## 解的概念

- **通解**：含任意常数，常数个数一般等于阶数  
- **特解**：由初值/边值确定常数后的具体解  
- **解析解**：能用初等函数、积分等显式写出  
- **数值解**：在离散时间点上给出近似值（数模中最常用）

存在唯一性（皮卡定理，直观版）：若 $f(t,y)$ 对 $y$ 满足利普希茨条件，则初值问题在局部有唯一解。

---

## 数模中为何常用微分方程

1. **机理清晰**：变化率 = 流入 − 流出 + 生成 − 消耗  
2. **可解释参数**：增长率、传染率、衰减系数都有实际含义  
3. **可做定性分析**：平衡点、稳定性、阈值，不一定非要求出显式解  
4. **与差分方程对应**：离散数据、迭代模型可用差分（见 9.4）

---

## 典型一阶形式速览

| 类型 | 形式 | 解法提示 |
|------|------|----------|
| 可分离变量 | $y' = g(t)h(y)$ | $\int dy/h = \int g\,dt$ |
| 一阶线性 | $y' + P(t)y = Q(t)$ | 积分因子 $e^{\int P\,dt}$ |
| 齐次 | $y' = f(y/t)$ | 令 $u=y/t$ |
| 恰当方程 | $M\,dt + N\,dy = 0$ 且 $M_y=N_t$ | 找势函数 |

高阶、非线性、变系数问题多数靠**数值解**（见 9.6）。

---

## 建模的一般步骤

```
实际问题 → 变量与假设 → 变化率关系（机理）
    → 列出 DE + 初边值 → 解析/数值求解
    → 参数估计与检验 → 预测/解释/灵敏度
```

**质量守恒/平衡思想**（隔室模型）：

$$
\frac{dQ}{dt} = \text{输入速率} - \text{输出速率}
$$

人口、药物浓度、污染物、库存等都可以这样写。

---

## 与差分、随机模型的边界

| 模型 | 适用 |
|------|------|
| 连续 ODE/PDE | 时间/空间可视为连续，量大 |
| 差分方程 | 代际、按年/按日统计、迭代 |
| 随机微分方程 SDE | 强噪声、小种群波动（提高要求） |
