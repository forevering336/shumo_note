# 9.1 微分方程基础概念

**微分方程**（Differential Equation）是联系未知函数与其导数（或偏导数）的方程。当系统的变化率依赖于当前状态时——人口增长、传染病传播、冷却、振动、扩散等——微分方程是最自然的建模语言。

---

## 基本术语

| 术语 | 含义 |
|------|------|
| **常微分方程 ODE** | 未知函数只依赖一个自变量（通常是时间 $t$） |
| **偏微分方程 PDE** | 未知函数依赖多个自变量（如 $x,t$ 或 $x,y$） |
| **阶** | 方程中出现的最高阶导数的阶数 |
| **线性 / 非线性** | 未知函数及其导数是否只以一次式出现 |
| **初值问题 IVP** | 方程 + 初始时刻的状态 |
| **边值问题 BVP** | 方程 + 边界上的条件 |

一般 $n$ 阶 ODE 可写为：

$$
F\big(t, y, y', y'', \ldots, y^{(n)}\big) = 0
$$

常化为**一阶方程组**：

$$
\mathbf{y}' = \mathbf{f}(t, \mathbf{y}), \quad \mathbf{y}(t_0) = \mathbf{y}_0
$$

---

## 解的概念

- **通解**：含任意常数，常数个数一般等于阶数  
- **特解**：由初值/边值确定常数后的具体解  
- **解析解**：能用初等函数、积分等显式写出  
- **数值解**：在离散时间点上给出近似值（数模中最常用）

存在唯一性（皮卡–林德勒夫定理，直观版）：若 $f(t,y)$ 在初值附近连续，且对 $y$ 局部满足利普希茨条件，则初值问题在局部存在唯一解。这个结论说明模型给定同一初态后不会产生两条互相矛盾的轨迹；它并不自动保证解对所有时间都存在。

---

## 数模中为何常用微分方程

1. **机理清晰**：变化率 = 流入 − 流出 + 生成 − 消耗  
2. **可解释参数**：增长率、传染率、衰减系数都有实际含义  
3. **可做定性分析**：平衡点、稳定性、阈值，不一定非要求出显式解  
4. **与差分方程对应**：离散数据、迭代模型可用差分（见 9.4）

### 什么时候会想到微分方程

题目反复描述“变化率”或连续转移时，通常可以从微分方程入手。例如：

- “单位时间内增加/减少多少”“增长速度与现有数量成正比”；
- 多个群体之间持续转移，如易感者变成感染者、药物在隔室间交换；
- 系统具有连续的累积、扩散、衰减、振动或反馈过程；
- 题目不仅要求预测数值，还要求解释长期趋势、阈值或稳定性。

如果数据只在离散周期更新，且“每一期到下一期”的规则更自然，优先考虑差分方程；若随机波动是主要矛盾，则应进一步考虑随机过程或随机微分方程。

---

## 典型一阶形式速览

| 类型 | 形式 | 解法提示 |
|------|------|----------|
| 可分离变量 | $y' = g(t)h(y)$ | $\int dy/h = \int g\,dt$ |
| 一阶线性 | $y' + P(t)y = Q(t)$ | 积分因子 $e^{\int P\,dt}$ |
| 齐次 | $y' = f(y/t)$ | 令 $u=y/t$ |
| 恰当方程 | $M\,dt + N\,dy = 0$ 且 $M_y=N_t$ | 找势函数 |

高阶、非线性、变系数问题多数靠**数值解**（见 9.6）。

---

## 建模的一般步骤

```
实际问题 → 变量与假设 → 变化率关系（机理）
    → 列出 DE + 初边值 → 解析/数值求解
    → 参数估计与检验 → 预测/解释/灵敏度
```

**质量守恒/平衡思想**（隔室模型）：

$$
\frac{dQ}{dt} = \text{输入速率} - \text{输出速率}
$$

人口、药物浓度、污染物、库存等都可以这样写。

### 量纲检查

方程等号两边以及相加减的各项必须具有相同量纲。例如 $dN/dt$ 的单位是“人/天”，那么 $rN$ 中 $r$ 的单位必须是“$1$/天”。量纲不一致通常意味着漏乘了状态量、面积、体积或时间尺度。

### 一个完整模型应交代什么

1. 状态变量、参数及单位；
2. 关键假设及其适用范围；
3. 每个变化率项的来源与正负号；
4. 初值或边值从哪里获得；
5. 参数如何估计，模型如何检验；
6. 最终输出是预测曲线、阈值、平衡点还是控制策略。

---

## 与差分、随机模型的边界

| 模型 | 适用 |
|------|------|
| 连续 ODE/PDE | 时间/空间可视为连续，量大 |
| 差分方程 | 代际、按年/按日统计、迭代 |
| 随机微分方程 SDE | 强噪声、小种群波动（提高要求） |
