# 最小生成树

最小生成树（Minimum Spanning Tree，MST）是加权连通图中连接所有顶点且边权总和最小的生成树。MST问题是图论中的经典优化问题之一。

## 1 问题描述

在一个连通加权无向图中，寻找一棵包含所有顶点的树，使树中边的权值之和最小。

## 2 常见算法

### 2.1 Kruskal算法

按照边权从小到大排序，逐条加入边，若加入边不会形成环则保留。可以使用并查集检测环路。

时间复杂度：O(E log E)。

### 2.2 Prim算法

从任一顶点出发，逐步将最近邻边加入生成树，直到包含所有顶点。适合使用优先队列优化。

时间复杂度：O(E log V)。

### 2.3 Boruvka算法

在每一轮中，为每个连通分量选择一条最小边并合并，直到只剩一个连通分量。

## 3 MST性质

- 割性质：对于任意顶点划分的割，跨割中权值最小的边必属于某个最小生成树。
- 环性质：对于任意环，权值最大的边不属于任何最小生成树。
- 最小生成树不一定唯一，但所有最小生成树权值总和相等。

## 4 应用场景

- 网络设计：光纤铺设、通信网络、供电线路设计。
- 聚类分析：基于最小生成树的层次聚类。
- 近似算法：用于旅行商问题和图划分问题的近似解构造。

## 5 求解步骤

1. 构建加权无向图并读取边集合。
2. 选择合适的MST算法。
3. 采用排序或优先队列依次加入最小边。
4. 检查环路或维护连通集，直到所有顶点连接。

## 6 计算与检查

最小生成树只适用于连通无向图。若原图不连通，求得的是最小生成森林；若边有方向，则需要使用有向生成树等其他模型。

```python
import networkx as nx

G = nx.Graph()
G.add_weighted_edges_from([
    ("A", "B", 4),
    ("A", "C", 2),
    ("B", "C", 1),
    ("B", "D", 5),
    ("C", "D", 8),
])

T = nx.minimum_spanning_tree(G, weight="weight", algorithm="kruskal")
total = T.size(weight="weight")
print(list(T.edges(data=True)))
print("总权重:", total)
```

结果应包含 $|V|-1$ 条边且保持连通。若存在相同权重，最小生成树可能不唯一，但总权重相同。

## 7 小结

最小生成树适合“以最低建设成本连通全部节点”，不负责限制两点之间的实际行驶距离。若同时要求冗余、可靠性或节点度数，模型会变成带约束生成树或网络设计问题。
