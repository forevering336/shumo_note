# 图的基本概念

图是由顶点和边构成的数学结构，用于刻画对象之间的关系。图论在计算机科学、运筹学、网络分析、交通规划等领域有广泛应用。

## 1 图的基本定义

- 顶点（Vertex）：图中的基本元素，通常表示实体或节点。
- 边（Edge）：连接两个顶点的线段，表示顶点之间的关系。
- 无向图：边没有方向，边(u,v)与边(v,u)等价。
- 有向图：边具有方向，称为弧，从尾节点指向头节点。
- 简单图：没有自环和重边的图。
- 多重图：允许同一对顶点之间存在多条边。

## 2 图的分类

- 加权图：边带有权值，表示距离、成本、容量等。
- 无权图：边仅表示连接关系，不带权值。
- 稀疏图和稠密图：根据边数量相对于顶点数量的比例划分。
- 连通图：无向图中任意两个顶点之间存在路径。
- 强连通图：有向图中任意两个顶点之间均存在双向可达路径。

## 3 基本术语

- 邻接：如果顶点u和v之间存在边，则称它们相邻。
- 度：顶点的度是与之相连的边数。有向图中有出度和入度。
- 路径：由一系列连续边组成，用于连接两个顶点。
- 简单路径：路径中不重复顶点。
- 回路/环：起点和终点相同的路径。
- 最短路径：路径长度（或权值和）最小的路径。
- 子图：由原图的部分顶点和边构成的图。

## 4 图的表示方法

- 邻接矩阵：一个n×n矩阵，其中元素表示顶点之间是否存在边或边的权值。
- 邻接表：为每个顶点记录相邻顶点列表，适合稀疏图表示。
- 边列表：直接列出图的所有边及其属性。

## 5 特殊图类型

- 树：连通且无环的无向图。
- 森林：若干棵树的集合。
- 二分图：顶点集合可分为两个不相交部分，边仅在两个部分之间连接。
- 完全图：任意两顶点之间都有一条边。
- 线图、补图、子图等用于图结构变换与分析。

## 6 图模型的应用

- 社交网络分析：节点代表用户，边代表关系。
- 交通网络：节点代表城市或路口，边代表道路或航线。
- 电力与通信网络：分析网络连通性与容错能力。
- 任务调度与资源分配：构造调度图和匹配模型。

## 7 建模时先确定的事项

把实际问题画成图之前，至少确认：

1. 节点和边分别代表什么；
2. 边是否有方向，是否允许重复边和自环；
3. 权重代表距离、费用、时间、容量还是相似度；
4. 路径是否允许重复经过节点；
5. 问题关注连通、最短、最大流、匹配还是遍历。

邻接矩阵适合稠密图和矩阵运算，邻接表更适合道路、通信等稀疏网络。用 NetworkX 建图时可以先做一次基本检查：

```python
import networkx as nx

G = nx.DiGraph()
G.add_weighted_edges_from([
    ("A", "B", 4.0),
    ("A", "C", 2.0),
    ("C", "B", 1.0),
])

print("节点数:", G.number_of_nodes())
print("边数:", G.number_of_edges())
print("弱连通:", nx.is_weakly_connected(G))
```

有向图应区分弱连通与强连通。若实际道路可以双向通行，需要明确是添加两条有向边，还是直接使用无向图。
