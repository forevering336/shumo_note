# 最短路径问题

最短路径问题是寻找图中两个顶点之间代价最小路径的问题。最短路径模型广泛用于交通路线规划、物流调度、网络路由等领域。

## 1 问题描述

- 单源最短路径：给定一个源点，求源点到图中所有其他顶点的最短路径。
- 两点最短路径：求图中两个指定顶点之间的最短路径。
- 全源最短路径：求图中任意两顶点之间的最短路径。

## 2 常见算法

### 2.1 Dijkstra算法

适用于边权非负的有向或无向图。核心思想是从源点逐层扩展，维护已知最短距离集合，采用贪心策略选取当前最近顶点。

时间复杂度：O((V+E) log V)（使用优先队列）。

### 2.2 Bellman-Ford算法

适用于含有负权边但无负环的图。通过对边进行松弛操作，重复V-1次即可得到最短路径。

时间复杂度：O(VE)。

### 2.3 Floyd-Warshall算法

适用于计算任意两顶点之间的最短路径。采用动态规划思想，通过中间顶点逐步更新最短距离。

时间复杂度：O(V^3)。

### 2.4 SPFA算法

基于Bellman-Ford的优化版本，采用队列维护待松弛顶点。对部分图结构和数据分布较好的情况性能较优，但最坏情况下仍为O(VE)。

## 3 问题类型与变体

- 非负权最短路径：Dijkstra适用。
- 含负权边最短路径：Bellman-Ford或SPFA适用。
- 有负权环：问题无解或最短路径不存在。
- k-最短路径：寻找第k条最短简单路径或弯曲路径。

## 4 算法应用步骤

1. 构建图的邻接表示并初始化距离。
2. 选取合适算法。
3. 进行边松弛与距离更新。
4. 提取最短路径或距离结果。

## 5 示例说明

假设图中顶点A到其他顶点的边权如下：A-B=4, A-C=2, B-C=5, B-D=10, C-E=3, E-D=4。采用Dijkstra算法可求出A到D的最短路径为A→C→E→D，距离为9。

## 6 应用场景

- 公路、铁路和航空路线规划
- 数据包交换网络和通信路由
- 物流配送和应急救援路径选择
- 机器人导航与地图路径规划

## 7 数学表达与实现

设边 $(i,j)$ 的权重为 $w_{ij}$。单源最短路可以理解为反复进行松弛：

$$
d_j \leftarrow \min\{d_j,\ d_i+w_{ij}\}
$$

其中 $d_i$ 表示源点到节点 $i$ 的当前最短距离。Dijkstra 要求边权非负；若有负权边，应使用 Bellman-Ford 等算法，并检查负环。

```python
import networkx as nx

G = nx.DiGraph()
G.add_weighted_edges_from([
    ("A", "B", 4),
    ("A", "C", 2),
    ("C", "E", 3),
    ("E", "D", 4),
    ("B", "D", 10),
])

path = nx.shortest_path(G, "A", "D", weight="weight")
length = nx.shortest_path_length(G, "A", "D", weight="weight")
print(path, length)
```

输出路径后再按原始边权重新求和，可以避免节点编号或有向边设置错误。

## 8 小结

算法选择首先取决于边权和需要计算的源点数量。实际交通问题还可能同时受到容量、时间窗和转弯限制，此时普通最短路只是更复杂模型的一部分。
