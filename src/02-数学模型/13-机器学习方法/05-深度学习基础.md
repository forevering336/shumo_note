# 13.5 深度学习基础

**深度学习**用多层非线性变换自动学习表示，在图像、语音、文本、复杂序列上表现突出。数模中：小表格数据往往**树模型更稳**；有时空网格、图像、长序列时再考虑深度模型。

---

## 一、神经网络基本单元

一层全连接：

$$
\mathbf{h} = \sigma(W\mathbf{x}+\mathbf{b})
$$

$\sigma$ 为激活函数：ReLU、Sigmoid、Tanh 等。多层堆叠形成 MLP（多层感知机）。

**训练：** 损失函数（MSE、交叉熵）+ 反向传播 + 梯度下降变体（SGD、Adam）。

---

## 二、常见结构速览

| 结构 | 擅长 | 数模可能场景 |
|------|------|----------------|
| **MLP** | 一般向量特征 | 中等规模表格（通常不如 GBDT） |
| **CNN** | 局部相关、图像 | 遥感图、缺陷图像、网格场 |
| **RNN / LSTM / GRU** | 序列依赖 | 中小规模序列、在线或低延迟任务 |
| **Transformer** | 长程依赖、注意力 | 序列、多变量时序（提高） |
| **自编码器** | 降维、去噪 | 特征压缩、异常 |

---

## 三、训练中的关键技巧

1. **数据**：标准化/归一化；足够样本量；增强（图像）  
2. **正则**：Dropout、权重衰减、早停  
3. **学习率**：通常是最关键超参；Adam 适合作为起点，必要时配合 warmup 或调度
4. **批次与epoch**：监控验证集，防过拟合  
5. **可复现**：固定种子，记录结构与超参  

```python
# PyTorch 训练循环骨架（示意）
for epoch in range(epochs):
    model.train()
    for xb, yb in loader:
        opt.zero_grad()
        loss = criterion(model(xb), yb)
        loss.backward()
        opt.step()
```

完整训练还应包括 `model.eval()`、关闭梯度后的验证循环、早停、最佳权重保存和独立测试。上面的代码只是反向传播骨架，不能直接代表完整实验。

## 四、与传统 ML 如何选？

| 条件 | 建议 |
|------|------|
| 表格、$n$ 为百～万级、特征几十 | 优先 GBDT / 线性 |
| 图像、语音 | CNN / 预训练模型 |
| 长序列、多变量时序且数据量大 | LSTM / Temporal CNN / Transformer |
| 需要强解释、机理约束 | 浅模型或物理信息神经网络 PINN（提高） |

**PINN 简介：** 把微分方程残差写入损失函数，使网络解近似满足物理定律，适合机理 + 数据融合（研究向）。

PINN 并非传统数值方法的普遍替代品：它可能训练困难、对损失权重和采样点敏感，在刚性、多尺度或高频问题上未必占优。使用时应与有限差分、ODE/PDE 求解器或纯数据模型作基线比较。

### 迁移学习

图像、文本等任务样本有限时，优先使用预训练模型并微调，而不是从零训练大型网络。应明确预训练数据来源，避免测试数据或高度相似样本进入预训练/训练过程造成隐性泄漏。

## 五、实验中需要交代的内容

- 写清网络结构（层数、激活、输出维）  
- 损失函数、优化器、学习率、训练轮数  
- 与传统模型对比表  
- 避免只贴训练曲线不报测试集指标  
- 报告验证策略、随机种子、早停规则和最佳模型选择依据
- 对比参数量、训练时间与简单模型，说明复杂度是否必要

---

## 小结

深度学习能拟合复杂关系，但不必作为默认选择。决定使用前先看数据类型、样本量和简单模型的表现；使用后要把验证、早停、复现和误差分析写完整，网络结构图本身不能说明模型有效。
