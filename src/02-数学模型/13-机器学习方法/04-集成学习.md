# 13.4 集成学习

**集成学习**把多个基学习器的结果组合起来，目的是降低单个模型的偶然误差。随机森林和梯度提升树在表格数据上经常有效，但是否优于线性模型或单棵树仍要用验证结果判断。

---

## 一、三大思路

| 范式 | 思想 | 代表 |
|------|------|------|
| **Bagging** | 平行训练，降方差 | 随机森林 |
| **Boosting** | 串行关注残差，降偏差 | AdaBoost、GBDT、XGBoost、LightGBM |
| **Stacking / Blending** | 用元模型融合异构基模型 | 多层堆叠 |

---

## 二、随机森林（Bagging + 树）

- 对样本 bootstrap 抽样，对特征随机子集分裂  
- 分类：投票；回归：平均  
- 优点：抗过拟合相对较好、可计算特征重要性、能表达非线性与交互
- 缺点：模型大，外推弱于机理模型  

不同实现对缺失值的支持不同；最稳妥的做法仍是把缺失值处理放进流水线并在交叉验证中完成。

主要超参：`n_estimators`，`max_depth`，`min_samples_leaf`，`max_features`。

---

## 三、梯度提升树（GBDT 族）

迭代地拟合负梯度（残差方向）：

$$
F_m(x) = F_{m-1}(x) + \nu\, h_m(x)
$$

$\nu$ 为学习率，$h_m$ 为新树。

| 实现 | 特点 |
|------|------|
| sklearn `GradientBoosting*` | 标准实现，中等规模 |
| **XGBoost** | 正则、二阶信息、工程强 |
| **LightGBM** | 直方图、叶子生长，大数据更快 |
| CatBoost | 类别特征处理优秀 |

**调参直觉：** 先小学习率 + 足够树棵数；控制深度（常用 3–8）；用早停；子采样、列采样防过拟合。

```python
from xgboost import XGBRegressor
model = XGBRegressor(
    n_estimators=500, learning_rate=0.05, max_depth=5,
    subsample=0.8, colsample_bytree=0.8,
    early_stopping_rounds=50, random_state=42
)
model.fit(X_train, y_train, eval_set=[(X_val, y_val)], verbose=False)
```

不同 XGBoost 版本的早停参数位置可能不同，运行前应查看本机版本文档。早停所用验证集不能再作为最终测试集。

---

## 四、投票与堆叠

- **Voting**：硬投票（类标签）/ 软投票（平均概率）  
- **Stacking**：基模型预测作为元特征，再训练逻辑回归等元学习器；注意用**折外预测**防泄漏  

折外预测（out-of-fold prediction）指：每个训练样本的元特征必须由“没有训练过该样本”的基模型产生。若直接用基模型在自身训练集上的预测训练元模型，Stacking 会严重过拟合。

---

## 五、使用建议（数模）

1. 先线性/单树基线，再上 RF / LightGBM 对比  
2. 样本量很小时集成可能过拟合，加强正则与交叉验证  
3. 报告特征重要性，呼应问题背景  
4. 与机理模型**组合预测**（第 12 章）往往更稳  
5. 比较训练时间、推理成本和模型大小，精度微增不一定值得增加复杂度

---

## 六、解释与不确定性

- 使用排列重要性或 SHAP 解释特征贡献，并检查不同折之间是否稳定；
- 用交叉验证折间波动或 bootstrap 给出性能不确定性；
- 对超出训练范围的数据标记外推风险，树模型通常无法可靠线性外推；
- 若类别极不平衡，除 ROC-AUC 外同时报告 PR-AUC、召回率与阈值。

---

## 小结

Bagging 主要通过平均降低方差，Boosting 则逐步修正前一轮的误差。表格数据可以比较随机森林、梯度提升树和线性基线；若性能差别很小，浅树或线性模型往往更容易解释和复现。
