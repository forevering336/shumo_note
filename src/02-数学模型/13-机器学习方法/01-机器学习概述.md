# 13.1 机器学习概述

**机器学习**（Machine Learning）让计算机从数据中自动改进性能，而无需为每种情况手写规则。在数模中，它是**数据驱动建模**的重要补充：当机理不明、非线性强、特征多时，ML 往往比纯机理模型更易出结果。

---

## 一、基本设定

给定训练数据 $\{(x_i, y_i)\}_{i=1}^n$ 或仅 $\{x_i\}$：

| 范式 | 标签 | 目标 | 例子 |
|------|------|------|------|
| **监督学习** | 有 $y$ | 学 $f:x\mapsto y$ | 回归、分类 |
| **无监督学习** | 无 $y$ | 发现结构 | 聚类、降维 |
| **半监督** | 少量 $y$ | 利用未标注 | 标签昂贵时 |
| **强化学习** | 奖励信号 | 学策略 | 博弈、控制（赛题较少） |

---

## 二、典型流程

```
问题定义 → 数据清洗与特征工程 → 划分训练/验证/测试
    → 选择模型 → 训练 → 调参与验证 → 测试集评估 → 解释与部署
```

**特征工程**往往比“换更复杂模型”更能提分：缺失值、标准化、编码类别、构造交互/滞后特征、降维等。

---

## 三、偏差–方差权衡

- **欠拟合**：模型太简，训练误差高（高偏差）  
- **过拟合**：死记训练噪声，泛化差（高方差）  

对策：更多数据、正则化、早停、交叉验证、集成、简化模型。

---

## 四、数模中何时用 ML？

| 更适合 ML | 更适合机理/统计模型 |
|-----------|---------------------|
| 特征多、关系黑箱 | 需要参数可解释、政策含义 |
| 预测精度优先 | 小样本、强先验机理 |
| 图像、文本、复杂表格 | 经典题型（优化、ODE、评价） |

**务实策略：** 机理模型作主线 + ML 作预测/残差修正/分类辅助；或 ML 作强基线再解释。

---

## 五、常用工具

| 库 | 用途 |
|----|------|
| `scikit-learn` | 经典 ML 一站式 |
| `xgboost` / `lightgbm` | 表格数据利器 |
| `pytorch` / `tensorflow` | 深度学习 |
| `pandas` / `numpy` | 数据与数值 |

---

## 小结

机器学习 = **数据 + 假设空间 + 学习算法 + 评价**。后续按监督、无监督、集成、深度、评估调参展开；始终用验证集说话，避免“只报训练集分数”。
