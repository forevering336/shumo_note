# 13.6 模型评估与调参

没有可靠评估，再复杂的模型也只是“看起来能拟合”。本节给出数模论文中应固定下来的**指标、验证方案与调参流程**。

---

## 一、数据集划分

| 方式 | 做法 | 适用 |
|------|------|------|
| 持出法 | train / val / test | 数据充足 |
| $K$ 折交叉验证 | 轮流当验证 | 中小样本，更稳 |
| 分层 K 折 | 保持类别比例 | 分类不平衡 |
| 时间序列切分 | 按时间前训后测 | **禁止随机打乱时序** |
| 分组切分 | 同实体不跨集合 | 防泄漏 |

最终报告以**测试集**（或嵌套 CV 的外层）为准；调参只看验证集。

所有会从数据估计参数的预处理——缺失值填补、标准化、编码、PCA、特征筛选——都必须在每个训练折内拟合。先处理完整数据再交叉验证会造成泄漏。

---

## 二、回归指标

设 $y_i$ 真值，$\hat y_i$ 预测：

| 指标 | 公式要点 | 特点 |
|------|----------|------|
| MAE | $\frac{1}{n}\sum |y-\hat y|$ | 稳健、同量纲 |
| MSE / RMSE | 平方 / 开方 | 对大误差敏感 |
| MAPE | 百分比绝对误差 | 注意 $y\approx 0$ |
| $R^2$ | 解释方差比例 | 可与基线比 |

$R^2$ 在测试集上可能为负，表示模型还不如直接预测训练集均值。指标应根据题目代价选择：大误差代价高用 RMSE，强调典型绝对偏差用 MAE；目标接近 0 或可为负时不宜用 MAPE。

---

## 三、分类指标

| 指标 | 含义 |
|------|------|
| Accuracy | 总体正确率（不平衡时慎用） |
| Precision / Recall | 查准 / 查全 |
| F1 | 二者调和平均 |
| AUC-ROC | 排序能力，阈值无关 |
| PR-AUC | 关注正类且类别极不平衡时更有信息 |
| Log Loss / Brier | 概率预测的准确性与校准 |
| 混淆矩阵 | 各类对错分布，论文宜展示 |

多分类：macro / micro / weighted 平均 F1。

AUC-ROC 衡量排序而非概率校准；同一个 AUC 下，预测概率可能非常不可靠。需要风险概率时应同时查看校准曲线或 Brier 分数。

---

## 四、调参方法

1. **人工经验**：学习率、树深、正则强度  
2. **网格搜索** `GridSearchCV`：小空间穷举  
3. **随机搜索** `RandomizedSearchCV`：大空间更高效  
4. **贝叶斯优化**（Optuna 等）：试验次数有限时  

原则：

- 先粗搜再细搜  
- 同步用交叉验证  
- 记录随机种子与搜索空间  
- 警惕在测试集上反复试参（信息泄漏）  
- 搜索空间、预处理与模型一起放入 `Pipeline`
- 比较交叉验证均值时也看标准差，微小差异可能只是抽样波动

```python
from sklearn.model_selection import GridSearchCV
from sklearn.ensemble import RandomForestRegressor

param = {'max_depth':[3,5,8], 'n_estimators':[100,300]}
gs = GridSearchCV(RandomForestRegressor(random_state=42),
                  param, cv=5, scoring='neg_root_mean_squared_error')
gs.fit(X_train, y_train)
print(gs.best_params_, gs.best_score_)
```

## 五、学习曲线与诊断

- **训练分很高、验证分很低** → 过拟合：加正则、减复杂度、加数据  
- **训练与验证都低** → 欠拟合：增容模型、改进特征  
- **学习曲线随 $n$ 上升仍有空间** → 多采集数据有益  

还应做分组误差分析：按时间、地区、类别、数值区间等拆分指标，防止总体平均掩盖某些群体上的系统性失败。

---

## 六、结果表中建议保留什么

1. 数据划分方式与比例  
2. 指标定义  
3. 多模型对比表（含简单基线：均值预测、线性回归）  
4. 最优超参  
5. 误差分析（哪类样本错得多、残差图）  
6. 稳定性：不同种子或折的均值±标准差  

### 推荐对比表

| 模型 | 验证指标（均值±标准差） | 测试指标 | 训练时间 | 备注 |
|------|-------------------------|----------|----------|------|
| 简单基线 | … | … | … | 均值/多数类/上一期 |
| 可解释模型 | … | … | … | 线性或浅树 |
| 候选强模型 | … | … | … | 调参后的集成模型 |

当多个模型性能接近时，优先选择更简单、稳定、易解释的模型。不要把测试集用于选出表中“最好”的一行；模型选择应在验证阶段完成。

---

## 小结

评价的顺序应固定下来：先确定数据怎样切分和使用什么指标，再在验证数据上选模型与参数，最后才查看测试结果。这样得到的分数才接近模型面对新数据时的表现，也便于解释误差来自哪里。
