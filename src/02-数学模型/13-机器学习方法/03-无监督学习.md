# 13.3 无监督学习

无监督学习在**没有标签**时挖掘数据内在结构：分组、降维、异常模式。常用于探索分析、特征压缩、客户分群、异常检测。

---

## 一、聚类

目标：使簇内相似、簇间疏远。

| 算法 | 思想 | 特点 |
|------|------|------|
| **K-Means** | 最小化簇内平方和 | 需指定 $K$，球形簇，快 |
| **层次聚类** | 凝聚/分裂树状图 | 建树时无需预设 $K$，最终切树仍需选择簇数 |
| **DBSCAN** | 密度连通 | 任意形状，可标噪声，需邻域参数 |
| **GMM** | 高斯混合 + EM | 软聚类，椭球簇 |

**$K$ 的选择：** 肘部法、轮廓系数、聚类稳定性与业务可解释性。轮廓系数偏好分离清晰的凸簇，不应作为唯一依据。

```python
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler

Xs = StandardScaler().fit_transform(X)
km = KMeans(n_clusters=4, random_state=42, n_init=10).fit(Xs)
labels = km.labels_
```

**注意：** 基于距离的聚类通常要**标准化**；类别特征不能随意编码成连续数字后直接计算欧氏距离，可考虑合适的相异度或专用算法；结果需结合业务特征命名簇。

## 二、降维

| 方法 | 类型 | 用途 |
|------|------|------|
| **PCA** | 线性 | 方差最大投影、去相关、可视化 |
| 核 PCA | 非线性 | 弯曲流形（中小数据） |
| t-SNE / UMAP | 非线性 | 二维可视化（非严格“特征”） |
| 自编码器 | 神经网络 | 非线性压缩 |

PCA：对中心化数据做协方差特征分解，取前 $k$ 个主成分。若各变量单位差异大，通常先标准化；累计方差贡献率与下游任务表现共同帮助选择 $k$。

t-SNE/UMAP 的二维图主要用于探索局部邻域，不宜把图上簇间距离解释为原空间中的精确远近，也不宜只凭一张图宣称存在天然类别。不同随机种子和参数下应检查结构是否稳定。

---

## 三、异常检测（简述）

- 统计：$3\sigma$、IQR  
- 模型：Isolation Forest、LOF、One-Class SVM  
- 用于清洗数据或“故障/欺诈”类问题  

异常点不一定是错误数据，也可能正是研究对象。删除前应追溯成因，并分别报告“保留/处理异常点”时结论是否改变。无标签异常检测可用已知案例、人工复核或注入异常进行间接评价。

---

## 四、数模中的典型用法

1. 指标多 → PCA 降维再评价/回归  
2. 用户/地区无标签 → 聚类分型再分别建模  
3. 高维可视化 → PCA/t-SNE 展示结构  
4. 清洗 → 异常检测标记离群点

## 五、聚类结果的验证与解释

| 角度 | 检查方式 |
|------|----------|
| 内部有效性 | 轮廓系数、Calinski–Harabasz、Davies–Bouldin |
| 稳定性 | 重采样或更换种子后，簇结构是否相近 |
| 外部有效性 | 若有参考标签，用 ARI/NMI，但不把标签用于训练 |
| 业务意义 | 各簇样本量、中心特征、典型样本是否可解释 |

不要只给聚类散点图。论文中应提供每簇规模、关键变量统计和清晰命名，并说明算法、距离、标准化方法和参数依据。

## 小结

无监督不追求“准确率”，而追求**可解释的结构**。报告中应写清预处理、参数选择依据（轮廓系数/方差贡献）及簇的业务含义。
