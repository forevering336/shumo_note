# 13.3 无监督学习

无监督学习在**没有标签**时挖掘数据内在结构：分组、降维、异常模式。常用于探索分析、特征压缩、客户分群、异常检测。

---

## 一、聚类

目标：使簇内相似、簇间疏远。

| 算法 | 思想 | 特点 |
|------|------|------|
| **K-Means** | 最小化簇内平方和 | 需指定 $K$，球形簇，快 |
| **层次聚类** | 凝聚/分裂树状图 | 可不预指定 $K$，可看树 |
| **DBSCAN** | 密度连通 | 任意形状，可标噪声，需邻域参数 |
| **GMM** | 高斯混合 + EM | 软聚类，椭球簇 |

**$K$ 的选择：** 肘部法、轮廓系数、业务可解释性。

```python
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler

Xs = StandardScaler().fit_transform(X)
km = KMeans(n_clusters=4, random_state=42, n_init=10).fit(Xs)
labels = km.labels_
```

**注意：** 聚类前通常要**标准化**；类别特征需编码；结果需结合业务命名簇。

## 二、降维

| 方法 | 类型 | 用途 |
|------|------|------|
| **PCA** | 线性 | 方差最大投影、去相关、可视化 |
| 核 PCA | 非线性 | 弯曲流形（中小数据） |
| t-SNE / UMAP | 非线性 | 二维可视化（非严格“特征”） |
| 自编码器 | 神经网络 | 非线性压缩 |

PCA：对中心化数据做协方差特征分解，取前 $k$ 个主成分。累计方差贡献率帮助选 $k$。

---

## 三、异常检测（简述）

- 统计：$3\sigma$、IQR  
- 模型：Isolation Forest、LOF、One-Class SVM  
- 用于清洗数据或“故障/欺诈”类问题  

---

## 四、数模中的典型用法

1. 指标多 → PCA 降维再评价/回归  
2. 用户/地区无标签 → 聚类分型再分别建模  
3. 高维可视化 → PCA/t-SNE 展示结构  
4. 清洗 → 异常检测标记离群点  

---

## 小结

无监督不追求“准确率”，而追求**可解释的结构**。报告中应写清预处理、参数选择依据（轮廓系数/方差贡献）及簇的业务含义。
