# 7.2 优化问题的分类

优化问题可从多个维度分类。分类的意义不在于背名词，而在于：**判断问题属于哪一类，就能大致知道难度、可用算法和软件接口**。

---

## 六大常用分类

| 分类维度 | 两类 | 判断依据 | 详见 |
|----------|------|----------|------|
| 变量取值 | 连续 / 离散 | 决策变量是否必须取整数或有限集合 | 7.3 |
| 约束有无 | 无约束 / 有约束 | 是否存在等式或不等式约束 | 7.4 |
| 随机性 | 确定性 / 随机 | 参数是否含随机变量 | 7.5 |
| 线性性 | 线性 / 非线性 | 目标与约束是否全为线性 | 7.6 |
| 凸性 | 凸 / 非凸 | 目标与可行域是否凸 | 7.7 |
| 时间结构 | 静态 / 动态 | 决策是否随时间分阶段进行 | 7.8 |

说明：同一问题可以同时属于多个维度，例如“带整数变量的非线性非凸约束优化”。

---

## 按算法与难度的直觉

```
易 → 难（一般趋势，非绝对）

线性规划 (LP)
  → 凸二次规划 / 凸优化
    → 非线性连续优化
      → 混合整数线性规划 (MILP)
        → 混合整数非线性 / 非凸组合优化
```

- **LP / 凸优化**：有成熟多项式时间或高效内点法，大规模也可解  
- **整数规划**：NP-hard，小中规模可用分支定界、割平面  
- **非凸 / 组合爆炸问题**：常需启发式（遗传算法、模拟退火、粒子群）或问题结构专用算法  

---

## 按目标与约束数量

| 类型 | 含义 | 数模注意点 |
|------|------|------------|
| 单目标 | 一个 $f(x)$ | 最常见，直接 min/max |
| 多目标 | 多个冲突目标 | 加权和、ε-约束、Pareto 前沿；论文需说明权衡 |
| 单层 / 双层 | 是否嵌套优化 | 如 Stackelberg 博弈、设施选址上层+下层用户均衡 |

---

## 数模选题时的快速对照

| 题型特征 | 优先考虑 |
|----------|----------|
| 资源分配、生产计划、运输 | 线性规划 / 整数规划 |
| 路径、网络流、指派 | 图论 + 网络优化 |
| 拟合参数、最小误差 | 无约束或有界非线性最小二乘 |
| 需求不确定、随机场景 | 随机规划 / 鲁棒优化 |
| 多阶段决策、库存动态 | 动态规划 |
| 评价排序后做方案优选 | 先评价再优化，或双目标 |

---

## 小结

分类表是“导航图”：先判定连续还是离散、有没有约束、是否线性与凸、是否随机与动态，再进入对应章节选模型与算法。**接下来各节将逐一展开**。
