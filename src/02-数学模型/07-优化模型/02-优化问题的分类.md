# 7.2 优化问题的分类

优化问题可从多个维度分类。分类的意义不在于背名词，而在于：**判断问题属于哪一类，就能大致知道难度、可用算法和软件接口**。

---

## 六大常用分类

| 分类维度 | 两类 | 判断依据 | 详见 |
|----------|------|----------|------|
| 变量取值 | 连续 / 离散 | 决策变量是否必须取整数或有限集合 | [7.3](03-连续和离散优化问题.md) |
| 约束有无 | 无约束 / 有约束 | 是否存在等式或不等式约束 | [7.4](04-无约束和约束优化问题.md) |
| 随机性 | 确定性 / 随机 | 建模时是否显式考虑未知参数或随机变量 | [7.5](05-随机和确定性优化问题.md) |
| 线性性 | 线性 / 非线性 | 目标与约束是否全为线性 | [7.6](06-线性和非线性优化问题.md) |
| 凸性 | 凸 / 非凸 | 最小化目标与可行域是否满足凸性 | [7.7](07-凸和非凸优化问题.md) |
| 时间结构 | 静态 / 动态 | 决策是否与状态随时间共同演化 | [7.8](08-静态和动态优化问题.md) |

说明：同一问题可以同时属于多个维度，例如“带整数变量的非线性非凸约束优化”。

---

## 哪些结构会影响求解难度

优化问题很难排成一条固定的“由易到难”顺序。一个稀疏的大型线性模型可能很好解，一个变量不多但非凸或含整数逻辑的模型反而可能很慢。通常先看下面几件事：变量中是否有整数，连续部分是否凸，约束是否稀疏，以及模型能否分解成若干子问题。

- **LP / 凸优化**：理论和算法较成熟，能否解到很大规模仍取决于矩阵结构、精度要求和计算资源；
- **整数规划**：一般情形较难，但分支定界、割平面和问题结构常能解决实际规模；
- **非凸连续问题**：先看是否能利用可微性、特殊结构或凸松弛，不应一开始就使用元启发式；
- **组合问题**：优先考虑网络流、动态规划等专用算法，通用启发式放在精确方法难以承受时使用。

---

## 按目标与约束数量

| 类型 | 含义 | 数模注意点 |
|------|------|------------|
| 单目标 | 一个 $f(x)$ | 最常见，直接 min/max |
| 多目标 | 多个冲突目标 | 加权和、ε-约束、Pareto 前沿；论文需说明权衡 |
| 单层 / 双层 | 是否嵌套优化 | 如 Stackelberg 博弈、设施选址上层+下层用户均衡 |

---

## 数模选题时的快速对照

| 题型特征 | 优先考虑 |
|----------|----------|
| 资源分配、生产计划、运输 | 线性规划 / 整数规划 |
| 路径、网络流、指派 | 图论 + 网络优化 |
| 拟合参数、最小误差 | 无约束或有界非线性最小二乘 |
| 需求不确定、随机场景 | 随机规划 / 鲁棒优化 |
| 多阶段决策、库存动态 | 动态规划 |
| 评价排序后做方案优选 | 先评价再优化，或双目标 |

---

## 小结

实际建模时，同一个问题往往会同时落入几类。例如带启停决策的非线性排产，是混合整数、非线性、有约束的动态问题。先辨认最影响求解难度的结构，再决定是否需要简化或分解。
