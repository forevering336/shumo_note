# 第 7 章 · 优化模型

> 优化是数模中最核心的方法论之一。大部分数模题目最终都可以转化为某种优化问题。

---

## 7.1 线性规划 🟦🟢🟣 ⭐

### 是什么

在**线性约束条件**下，求**线性目标函数**的最大值或最小值。

标准形式：

$$
\begin{aligned}
\min \quad & \mathbf{c}^T \mathbf{x} \\
\text{s.t.} \quad & A\mathbf{x} \leq \mathbf{b} \\
& \mathbf{x} \geq 0
\end{aligned}
$$

### 在数模中怎么用

- **资源分配问题**：有限资源如何分配给不同任务以最大化收益
- **运输问题**：多个供应点到多个需求点的最小成本运输方案
- **生产计划**：在产能、原料约束下安排生产计划

典型题型：国赛 2003B（露天矿生产）、2005B（DVD 在线租赁）

### 核心知识点

- **可行域** — 所有约束条件的交集，线性规划的最优解一定在可行域的顶点上
- **单纯形法** — 经典的求解算法（知道原理即可，求解时不用手写）
- **对偶理论** — 每个线性规划问题都有一个对偶问题，有时对偶问题更好解
- **灵敏度分析** — 参数变化时最优解如何变化，论文里经常需要做

### 代码实现

```python
# 方法1: 用 scipy.optimize.linprog
from scipy.optimize import linprog
import numpy as np

# 问题: min c^T x  s.t. A_ub @ x <= b_ub, A_eq @ x == b_eq
c = np.array([-1, -2])           # 目标函数系数（负号因为 linprog 默认求 min）
A_ub = np.array([[2, 1],         # 不等式约束系数
                  [1, 2]])
b_ub = np.array([6, 6])          # 不等式约束右端

result = linprog(c, A_ub=A_ub, b_ub=b_ub)
print(f"最优解: x1={result.x[0]:.2f}, x2={result.x[1]:.2f}")
print(f"最优值: {-result.fun:.2f}")
```

```python
# 方法2: 用 PuLP（更接近数学模型写法，推荐）
from pulp import *

# 创建问题
prob = LpProblem("example", LpMaximize)

# 决策变量
x1 = LpVariable("x1", lowBound=0)
x2 = LpVariable("x2", lowBound=0)

# 目标函数
prob += x1 + 2 * x2

# 约束条件
prob += 2 * x1 + x2 <= 6
prob += x1 + 2 * x2 <= 6

# 求解
prob.solve()
print(f"最优解: x1={value(x1):.2f}, x2={value(x2):.2f}")
print(f"最优值: {value(prob.objective):.2f}")
```

### 常见坑

- ⚠️ `linprog` 默认求**最小值**，求最大值需要把目标函数系数取负
- ⚠️ 约束条件注意方向：$A_{ub} x \leq b_{ub}$，如果原问题是 ≥ 需要两边乘 -1
- ⚠️ 整数规划不能用 `linprog`，需要用 `milp` 或 PuLP 的 `LpInteger`

## 7.2 非线性规划 🟦🟢

### 是什么

目标函数或约束条件中至少有一个是**非线性函数**的优化问题。

$$
\begin{aligned}
\min \quad & f(x_1, x_2, \ldots, x_n) \\
\text{s.t.} \quad & g_i(x_1, \ldots, x_n) \leq 0, \quad i=1,\ldots,m \\
& h_j(x_1, \ldots, x_n) = 0, \quad j=1,\ldots,p
\end{aligned}
$$

### 在数模中怎么用

- **曲线拟合** — 最小二乘法本质上就是非线性优化
- **参数估计** — 已知模型结构，反推最优参数
- **工程设计优化** — 结构最轻、成本最低等

### 核心知识点

- **梯度下降法** — 沿负梯度方向迭代，最基础的数值优化方法
- **牛顿法** — 利用二阶信息（Hessian 矩阵），收敛更快但计算量大
- **KKT 条件** — 非线性规划的最优性必要条件（有约束时）
- **凸优化** — 如果问题是凸的，局部最优 = 全局最优，大大简化求解

### 代码实现

```python
from scipy.optimize import minimize
import numpy as np

# 目标函数: f(x) = (x1-1)^2 + (x2-2)^2
def objective(x):
    return (x[0] - 1)**2 + (x[1] - 2)**2

# 约束: x1 + x2 >= 3  →  x1 + x2 - 3 >= 0
cons = [{'type': 'ineq', 'fun': lambda x: x[0] + x[1] - 3}]

x0 = np.array([0, 0])  # 初始猜测
result = minimize(objective, x0, constraints=cons)
print(f"最优解: {result.x}")
print(f"最优值: {result.fun}")
```

### 常见坑

- ⚠️ `minimize` 可能陷入**局部最优**，不同初始值可能得到不同结果
- ⚠️ 约束写成 `'ineq'` 表示 ≥ 0，`'eq'` 表示 = 0
- ⚠️ 变量较多时建议用 `method='L-BFGS-B'` 或 `'SLSQP'`

## 7.3 整数规划 🟦🟢 ⭐

### 是什么

决策变量必须取**整数值**的优化问题。最特殊也最常见的是 **0-1 规划**（变量只能取 0 或 1）。

### 在数模中怎么用

- **指派问题** — 人分配到任务，选或不选
- **选址问题** — 在哪些位置建设施
- **背包问题** — 选哪些物品使价值最大
- **排班/调度问题** — 人员排班、机器调度

### 核心知识点

- **NP-hard** — 整数规划通常比连续优化难得多，没有多项式时间算法
- **分支定界法** — 主流求解器的核心算法
- **割平面法** — 不断添加线性约束逼近整数解
- **松弛** — 先忽略整数约束求解，再逐步收紧（常见论文策略）

### 代码实现

```python
# PuLP 求解整数规划
from pulp import *

prob = LpProblem("knapsack", LpMaximize)

# 物品价值与重量
values = [10, 20, 15, 30]
weights = [2, 5, 3, 7]
capacity = 10
n = len(values)

# 0-1 变量
x = [LpVariable(f"x{i}", cat="Binary") for i in range(n)]

# 目标：最大化总价值
prob += lpSum(values[i] * x[i] for i in range(n))

# 约束：总重量 ≤ 容量
prob += lpSum(weights[i] * x[i] for i in range(n)) <= capacity

prob.solve()

print("选中的物品:")
for i in range(n):
    if value(x[i]) > 0.5:
        print(f"  物品{i+1}: 价值{values[i]}, 重量{weights[i]}")
```

### 常见坑

- ⚠️ 整数规划求解时间随变量数**指数增长**，变量太多（>1000）可能求解极慢
- ⚠️ 0-1 变量用 `cat="Binary"`，一般整数用 `cat="Integer"` 且设 `lowBound`
- ⚠️ 有时把整数约束**松弛**为连续变量再四舍五入也能得到不错的结果，但理论上不保证最优

## 7.4 多目标优化 🟦🟣

### 是什么

同时优化**多个相互冲突**的目标函数。比如既要成本最低又要质量最好——这两个目标通常是矛盾的。

### 在数模中怎么用

- **综合评价类题目** — 多个指标之间的权衡
- **资源与环境问题** — 经济效益 vs 环境影响
- **工程设计中** — 性能 vs 成本 vs 重量

### 核心知识点

- **Pareto 最优** — 不存在能在不损害其他目标的情况下改进某个目标的解
- **加权法** — 给每个目标赋予权重，转化为单目标（最常用）
- **ε-约束法** — 只优化一个目标，其余目标作为约束
- **层次分析法 (AHP)** — 主观确定权重的方法
- **TOPSIS** — 基于理想解距离的排序方法

### 代码实现

```python
# 加权法：把多目标转成单目标
import numpy as np

# 假设两个目标函数
def f1(x):  # 成本（越小越好）
    return x[0]**2 + x[1]**2

def f2(x):  # 性能（越小越好）
    return (x[0]-2)**2 + (x[1]-2)**2

# 加权组合
w1, w2 = 0.6, 0.4  # 权重和为 1
def combined(x):
    return w1 * f1(x) + w2 * f2(x)

# 然后用单目标优化方法求解
# ...
```

### 常见坑

- ⚠️ 加权法中**权重的选择**对结果影响很大，论文中需要做**灵敏度分析**
- ⚠️ 量纲不一致时必须先**归一化**，否则权重无意义
- ⚠️ 不要混淆"多目标优化"和"多指标评价"——前者求 Pareto 前沿，后者求综合排名
