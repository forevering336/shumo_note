# TOPSIS方法

TOPSIS（Technique for Order Preference by Similarity to Ideal Solution）是一种多准则决策分析方法。该方法基于理想解和负理想解的概念，通过比较各方案与正理想解的距离和与负理想解的距离，得到方案的相对贴近度，并据此对方案排序。

## 1 TOPSIS的基本思想

TOPSIS认为最佳方案应该具有以下两个特征：

- 与正理想解（Positive Ideal Solution，PIS）距离最小。
- 与负理想解（Negative Ideal Solution，NIS）距离最大。

正理想解由各评价指标的最好值构成；负理想解由各评价指标的最差值构成。通过计算每个方案与PIS和NIS的欧氏距离，再求相对贴近度，可对方案进行排序。

## 2 TOPSIS求解步骤

### 2.1 构建评价矩阵

设有m个方案和n个评价指标，评价矩阵为：

X = [x_ij]，其中x_ij表示方案i在指标j上的实际值。

### 2.2 指标标准化

由于评价指标可能具有不同量纲，需先规范化处理。常用的向量规范化公式为：

r_ij = x_ij / sqrt(∑_{i=1}^m x_ij^2)

生成规范化矩阵R = [r_ij]。

### 2.3 计算加权规范化矩阵

引入指标权重w_j，构造加权规范化值：

v_ij = w_j * r_ij

得到加权规范化矩阵V = [v_ij]。

### 2.4 确定正理想解与负理想解

对于收益型指标，正理想值为各指标的最大值，负理想值为最小值；对于成本型指标，正理想值为最小值，负理想值为最大值。即：

- 正理想解 A^+ = {v_1^+, v_2^+, ..., v_n^+}
- 负理想解 A^- = {v_1^-, v_2^-, ..., v_n^-}

其中：

- v_j^+ = max_i v_ij 或 min_i v_ij（视指标属性而定）
- v_j^- = min_i v_ij 或 max_i v_ij（视指标属性而定）

### 2.5 计算方案与理想解的距离

采用欧氏距离计算各方案与正理想解和负理想解的距离：

- d_i^+ = sqrt(∑_{j=1}^n (v_ij - v_j^+)^2)
- d_i^- = sqrt(∑_{j=1}^n (v_ij - v_j^-)^2)

### 2.6 计算相对贴近度并排序

相对贴近度定义为：

C_i^* = d_i^- / (d_i^+ + d_i^-)

C_i^* 值越大，方案越接近理想解。根据C_i^*对方案进行排序，取最大者为最优方案。

## 3 TOPSIS方法特点

- 不需要构造成对比较矩阵，计算过程较为简洁。
- 考虑了方案与正理想解和负理想解之间的距离，兼顾了“最优”和“最差”两个方面。
- 与AHP相比，TOPSIS更适合定量指标较为明确的评价问题。

## 4 TOPSIS的改进与扩展

TOPSIS方法可以结合其他技术进行扩展：

- 与AHP结合：先用AHP确定指标权重，再用TOPSIS进行排序。
- 模糊TOPSIS：处理评价指标或权重为模糊数的情况。
- 直觉模糊TOPSIS：适用于直觉模糊集环境的信息处理。
- 灰色TOPSIS：适用于数据不完整、样本较小的评价问题。
- 带权TOPSIS：引入指标权重、方案权重或决策者权重。

## 5 示例说明

假设有三个方案A、B、C，评价指标为成本、质量和交付时间。指标属性为：成本和交付时间为成本型，质量为收益型；权重分别为0.3、0.5、0.2。

1. 构造评价矩阵X。
2. 对矩阵进行规范化，得到R。
3. 加权得到V。
4. 计算正理想解A^+和负理想解A^-。
5. 计算各方案的d_i^+和d_i^-。
6. 计算C_i^*并排序。

若C_A^*=0.72、C_B^*=0.55、C_C^*=0.38，则排序为 A > B > C。

## 6 应用场景

TOPSIS广泛用于：

- 供应商评价与选择
- 项目优先级排序
- 产品设计方案比较
- 环境质量评价
- 绩效管理与资源配置

## 7 小结

TOPSIS是一种思想明确、计算方便的多准则排序方法，适用于定量评价指标较为明确的场景。其关键在于正确标准化指标、合理设置权重，并区分成本型与收益型指标。
