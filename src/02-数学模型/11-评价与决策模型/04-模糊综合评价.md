# 模糊综合评价

模糊综合评价是一种利用模糊数学理论处理不确定性和模糊性评价信息的综合评价方法。该方法将定性评价与定量评判相结合，通过建立模糊关系和模糊综合运算，得到评价对象的综合评分与排序。

## 1 模糊综合评价的基本概念

- 模糊集合：由元素及其隶属度组成的集合，元素对集合的归属程度在[0,1]之间。
- 隶属函数：表示元素属于模糊集合的程度函数，常见形式有三角形函数、梯形函数、高斯函数等。
- 评价等级集：用于表示评价结果的模糊等级，如优、良、中、差。
- 权重向量：表示各评价指标的重要性权重。

## 2 模糊综合评价的基本步骤

### 2.1 确定评价指标体系

建立评价目标和指标体系，选取若干评价指标，并划分为若干层次。指标可以包括定量指标和定性指标。

### 2.2 确定评价等级与隶属度

选择评价等级集，一般可设为：

- U = {优、良、中、差}

针对每个指标，设计隶属度函数或直接采用专家评价构造隶属度矩阵，反映每个方案在各等级上的隶属程度。

### 2.3 赋权并构造权重向量

根据评价指标的重要性，采用主观赋权、客观赋权或综合赋权方法，确定指标权重向量W = (w1, w2, ..., wn)，满足∑ w_i = 1。

### 2.4 构造模糊关系矩阵

对每个指标构造模糊评价向量R_i = (r_i1, r_i2, ..., r_im)，其中r_ij表示第i个指标对第j个评价等级的隶属度。将各指标评价向量组合成模糊关系矩阵：

R =
[ R_1
  R_2
  ...
  R_n ]

### 2.5 进行模糊综合运算

对权重向量W与模糊关系矩阵R进行运算，常用的运算规则为：

B = W ∘ R

其中“∘”表示模糊综合运算。常用的组合方式有加权平均法：

b_j = ∑_{i=1}^n w_i * r_ij,  j = 1, 2, ..., m

得到综合评价向量B = (b_1, b_2, ..., b_m)。

### 2.6 提出评价结果

综合评价向量B可以用于不同的结果表达方式：

- 直接判别法：以最大隶属度对应的评价等级作为最终评价结果。
- 加权平均法：对评价等级赋予分值，计算综合得分S = ∑_{j=1}^m b_j * s_j。
- 排序法：比较不同方案的综合评分或隶属度分布。

## 3 典型模糊综合评价模型

### 3.1 经典模糊综合评价

经典模糊综合评价采用权重向量与模糊关系矩阵的加权平均运算。适用于评价等级明确、隶属度易于构造的场景。

### 3.2 基于模糊数的评价

当指标值本身具有模糊性时，可将指标值表示为模糊数（如三角模糊数或梯形模糊数），并利用模糊数运算构造评价矩阵。

### 3.3 模糊层次分析法

将AHP与模糊综合评价结合，使用模糊成对比较矩阵计算权重，再进行模糊综合运算。

## 4 示例说明

假设某公司对三个项目方案进行评价，评价指标为技术水平、经济效益、环境影响，评价等级为{优、良、中、差}。权重向量为W = (0.4, 0.35, 0.25)。

1. 对每个指标给出隶属度向量：
   - 技术水平：R1 = (0.2, 0.6, 0.2, 0.0)
   - 经济效益：R2 = (0.1, 0.7, 0.2, 0.0)
   - 环境影响：R3 = (0.0, 0.5, 0.4, 0.1)
2. 构造模糊关系矩阵R。
3. 计算综合评价向量B：
   B = W ∘ R = (0.13, 0.61, 0.26, 0.03)
4. 若评分值为S = {90, 75, 60, 45}，则综合得分 = 0.13×90 + 0.61×75 + 0.26×60 + 0.03×45 ≈ 74.4。
5. 可将评价结果判为“良”。

## 5 模糊综合评价的优点与局限

### 优点

- 适合处理主观判断和模糊信息，能兼顾定性评价与定量分析。
- 结构简单，计算过程较为直接。
- 可与其他评价方法结合，增强模型的适用性。

### 局限

- 隶属度函数和评价等级划分带有主观性。
- 当指标较多时，构造模糊评价矩阵和权重判断需要大量专家参与。
- 结果解释依赖于评价等级的取值与分值设置。

## 6 应用场景

模糊综合评价常用于：

- 教育质量评价与学校排名
- 环境影响评价与生态评价
- 技术方案比较与项目评估
- 社会满意度调查与服务质量评价

## 7 计算形式

设权重向量为

$$
W=(w_1,\ldots,w_m),\qquad \sum_iw_i=1
$$

指标 $i$ 对各评价等级的隶属度组成矩阵 $R$，常用加权平均算子得到：

$$
B=WR
$$

$B$ 的各分量表示对象对各等级的综合隶属度。若要转成一个分数，可再与等级分值向量 $S$ 相乘：

$$
F=BS^T
$$

```python
import numpy as np

W = np.array([0.4, 0.35, 0.25])
R = np.array([
    [0.6, 0.3, 0.1],
    [0.3, 0.5, 0.2],
    [0.2, 0.4, 0.4],
])
grade_score = np.array([100, 80, 60])

B = W @ R
score = B @ grade_score
print("综合隶属度:", B)
print("综合分数:", score)
```

隶属函数是结果中最主观的部分。阈值来自标准、专家还是样本分布，应在正文交代，并测试阈值变化是否改变等级。

## 8 小结

模糊综合评价适合“优、良、一般”等边界模糊的判断。若原始指标都是精确数值且只需排序，TOPSIS等方法通常更直接。
