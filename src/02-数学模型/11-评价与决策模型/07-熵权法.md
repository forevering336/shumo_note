# 熵权法

熵权法是一种基于信息熵理论的客观赋权方法，用于确定评价指标的权重。该方法认为指标的信息量越大，对评价结果的影响越显著，应具有更高的权重；反之，信息越分散的指标权重越低。

## 1 熵权法的基本思想

熵在信息论中表示信息的不确定性或离散程度。对于评价指标，若各方案在该指标上的取值差异较大，则该指标提供的信息较多，权重应相应较高；若各方案的指标取值较为接近，该指标的信息量较小，权重应较低。

## 2 熵权法求解步骤

### 2.1 构建评价矩阵

设有m个方案、n个指标，原始评价矩阵为：

X = [x_ij]，其中x_ij表示方案i在指标j上的实际值。

### 2.2 指标无量纲化

对原始数据进行无量纲化处理，以消除不同指标量纲的影响。常见方法包括：

- 归一化（收益型）：r_ij = x_ij / ∑_{i=1}^m x_ij
- 归一化（成本型）：r_ij = min_i x_ij / x_ij

处理后得到标准化矩阵R = [r_ij]，满足∑_{i=1}^m r_ij = 1。

### 2.3 计算指标熵值

定义指标j的熵值为：

e_j = -k ∑_{i=1}^m r_ij ln r_ij

其中k = 1 / ln m，保证0 ≤ e_j ≤ 1。若r_ij = 0，则约定r_ij ln r_ij = 0。

### 2.4 计算信息效用值

信息效用值表示指标的差异程度：

d_j = 1 - e_j

d_j值越大，说明指标的区分能力越强。

### 2.5 计算权重向量

指标权重由信息效用值归一化得到：

w_j = d_j / ∑_{j=1}^n d_j

得到满足∑_{j=1}^n w_j = 1 的权重向量W。

## 3 熵权法的特点

- 客观性较强，不依赖专家主观判断。
- 适合用于指标数据变化较大、样本数量较多的评价问题。
- 与主观赋权方法结合，可构建综合权重，兼顾数据和经验信息。

## 4 熵权法的改进与应用

### 4.1 综合权重法

可将熵权法与AHP等主观赋权方法结合，采用加权平均或算术平均获得综合权重，减少单一方法的偏差。

### 4.2 带权熵权法

在计算指标熵值时，可引入专家给定的指标重要性系数，以调整客观权重的分布。

### 4.3 时域熵权法

对动态评价问题，可在不同时间点上分别计算指标熵权，分析权重随时间的变化。

## 5 示例说明

假设有三个方案A、B、C，两个指标x1（收益型）、x2（成本型），原始数据如下：

| 方案 | x1 | x2 |
|------|----|----|
| A    | 80 | 30 |
| B    | 70 | 40 |
| C    | 90 | 20 |

1. 对x1进行归一化：r_1 = [0.32, 0.28, 0.36]；对x2进行成本型归一化：r_2 = [0.67, 0.50, 1.00]。
2. 计算熵值e1和e2。
3. 得到信息效用值d1和d2。
4. 计算权重w1和w2。

通过熵权法获得的权重可用于TOPSIS、模糊综合评价等后续评价方法。

## 6 优缺点与适用范围

### 优点

- 提供客观权重，减少主观偏差。
- 能反映指标间的信息差异。

### 缺点

- 对数据量纲转换和标准化方法较敏感。
- 当样本较少时，熵值计算结果可能不稳定。

### 适用范围

适用于多指标评价、绩效分析和综合评价中需要客观赋权的场景。常与TOPSIS、DEA、模糊评价等方法结合使用。

## 7 小结

熵权法通过信息熵度量指标差异，为多指标评价提供了客观权重分配方案。结合其他评价方法可提高评价结果的鲁棒性和科学性。
