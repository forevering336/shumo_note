# 12.1 预测问题概述

**预测**（Prediction/Forecasting）是根据已知的历史数据和现有信息，运用科学的方法和手段，对未来尚未发生或当前不明确的事物进行估计和推断的过程。

一般地，预测问题可以表述为：已知某一系统在过去一段时间的观测数据 $\{y_1, y_2, \ldots, y_t\}$，要求预测未来时刻的值 $y_{t+1}, y_{t+2}, \ldots, y_{t+k}$，即：

$$
\hat{y}_{t+k} = f(y_t, y_{t-1}, \ldots, y_1; \theta)
$$

其中 $f$ 为预测模型，$\theta$ 为模型参数，$k$ 为预测步长（预测期数）。

---

## 预测的基本要素

一个完整的预测问题通常包含以下四个基本要素：

- **预测对象**：即需要预测的目标变量，可以是单一变量（单变量预测）或多个变量（多变量预测）。
- **预测依据**：用于建立预测模型的历史数据和相关信息，包括时间序列数据、横截面数据、面板数据等。
- **预测方法**：所采用的具体数学模型或算法，如回归分析、时间序列分析、灰色预测、神经网络等。
- **预测精度**：衡量预测结果与真实值之间偏差的指标，如均方误差（MSE）、平均绝对百分比误差（MAPE）等。

---

## 预测的基本原则

预测并非凭空猜想，而是建立在以下基本原则之上：

| 原则 | 含义 |
|------|------|
| **惯性原则** | 事物的过去和现在会持续影响未来，即系统的发展具有一定的延续性 |
| **类推原则** | 相似的事物在相似条件下会表现出相似的发展规律 |
| **相关原则** | 事物之间相互关联，一个变量的变化会引起其他变量的相应变化 |
| **概率推断原则** | 在不确定性条件下，依据概率统计方法进行合理推断 |

---

## 预测方法的分类

根据建模思想和数据特征的不同，预测方法可分为以下几类：

### 1. 定性预测方法
不依赖于定量数据，而是依靠专家经验、主观判断和逻辑推理做出预测。适用于数据匮乏或难以量化的场景。
- 德尔菲法（Delphi Method）
- 头脑风暴法
- 情景分析法

### 2. 定量预测方法
基于数学和统计模型，利用历史数据进行定量分析。

- **时间序列预测**：仅利用预测目标自身的历史数据，分析其随时间变化的统计规律，如移动平均法、指数平滑法、**ARIMA** 模型等。
- **因果分析预测（回归预测）**：寻找预测目标与其他相关因素之间的因果关系，建立回归方程进行预测，如**多元线性回归**、**非线性回归**等。
- **灰色预测**：适用于小样本、贫信息的不确定性系统，通过累加生成弱化随机性，挖掘系统内在规律，如 **GM(1,1)** 模型。
- **马尔可夫预测**：基于马尔可夫链理论，利用状态转移概率矩阵预测系统未来状态分布。
- **机器学习预测**：利用神经网络、支持向量机、随机森林等机器学习方法进行数据驱动的预测。
- **组合预测**：将多种单一预测方法进行合理组合，综合利用各方法的优势，提高预测精度和稳健性。

### 3. 类比预测方法
基于相似性原理，寻找与预测对象类似的参照物，参照其发展过程进行类比推断。

## 预测建模的一般步骤

预测建模遵循以下一般流程：

```
问题分析 → 数据收集与预处理 → 模型选择 → 模型建立与参数估计
    → 模型检验 → 预测与结果分析
```

1. **问题分析**：明确预测目标、预测对象及预测期限（短期/中期/长期），分析问题的背景和特点。
2. **数据收集与预处理**：收集相关历史数据；对异常值、缺失值进行处理；必要时对数据进行平滑、差分或标准化。
3. **模型选择**：根据数据特征（样本量、趋势性、季节性、非线性程度等）和问题需求选择合适的预测模型。
4. **模型建立与参数估计**：确定模型结构，利用历史数据估计模型参数（如最小二乘法、极大似然估计等）。
5. **模型检验**：通过拟合优度检验、残差分析、交叉验证等方法评估模型的合理性和有效性。
6. **预测与结果分析**：使用检验合格的模型进行预测，并分析预测结果的合理性和可靠性。

---

## 预测精度的评价指标

预测精度是指预测值与实际观测值之间的偏差程度。常用的评价指标有：

设 $y_i$ 为实际值，$\hat{y}_i$ 为预测值，$n$ 为样本数。

- **均方误差（MSE）**：$\displaystyle \text{MSE} = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2$
- **均方根误差（RMSE）**：$\displaystyle \text{RMSE} = \sqrt{\frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2}$
- **平均绝对误差（MAE）**：$\displaystyle \text{MAE} = \frac{1}{n} \sum_{i=1}^{n} |y_i - \hat{y}_i|$
- **平均绝对百分比误差（MAPE）**：$\displaystyle \text{MAPE} = \frac{1}{n} \sum_{i=1}^{n} \left| \frac{y_i - \hat{y}_i}{y_i} \right| \times 100\%$

通常采用**样本外预测**（out-of-sample prediction），将数据划分为训练集和测试集，用训练集建立模型，用测试集评价预测精度，以更客观地反映模型的泛化预测能力。

---

## 小结

预测问题是数学建模中一类重要的应用问题。预测的核心在于从历史数据中**挖掘规律、提取趋势**，并用数学模型加以描述和外推。合理选择和组合不同的预测方法，科学评价预测精度，是构建有效预测模型的关键。后续章节将逐一介绍各类典型的定量预测方法。
