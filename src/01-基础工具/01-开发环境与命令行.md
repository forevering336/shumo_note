## 1.1 为什么需要命令行

数模的日常：

- `pip install numpy scipy pulp` → 装库
- `python main.py` → 跑模型
- `git pull / push` → 跟队友同步
- `jupyter lab` → 打开 Notebook

以上全部在命令行里敲。图形界面能做，但命令行**更快、更可复现、比赛时不出意外**。

**最低要求**：会用 VS Code 内置终端（你已经会了，`Ctrl + `` 打开），能在里面敲命令就行。

## 1.3 命令行基础速查

### 进入和离开

```bash
cd "文件夹路径" # 进入目录
cd .. # 退回上一级
cd ~ # 回到用户目录
pwd # 显示当前所在目录（Windows 上没用，但知道就行）
```

### 查看文件

```bash
ls # 列出当前目录文件
ls -la # 列出详细信息（含隐藏文件）
dir # Windows 风格，跟 ls 差不多
```

### 文件操作

```bash
mkdir 文件夹名 # 创建文件夹
rm 文件名 # 删除文件（ 不可恢复）
rm -r 文件夹名 # 删除文件夹及其内容
cp 源文件 目标文件 # 复制
mv 源文件 目标文件 # 移动/重命名
```

### Python 相关

```bash
python --version # 查看 Python 版本
pip install 包名 # 安装 Python 包
pip list # 列出已安装的包
jupyter lab # 启动 Jupyter
```

### VS Code 终端小技巧

- `↑` 键 → 翻出上一条命令
- `Tab` 键 → 自动补全文件名
- `Ctrl + C` → 强制终止当前运行的命令
- 选中路径拖动到终端 → 自动粘贴路径

## 1.4 Python 虚拟环境

### 是什么

每个项目一个独立的 Python 环境，互相不干扰。笔记项目不需要（只是写 Markdown），但做赛题时建议用。

### 怎么用

```bash
# 创建虚拟环境
python -m venv myenv

# 激活（Windows）
myenv\Scripts\activate

# 激活后，pip install 的包只装在这个环境里
pip install numpy scipy pandas matplotlib pulp

# 退出
deactivate
```
