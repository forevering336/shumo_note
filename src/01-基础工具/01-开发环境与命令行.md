## 1.1 为什么需要命令行

数模的日常：

- `pip install numpy scipy pulp` → 装库
- `python main.py` → 跑模型
- `git pull / push` → 跟队友同步
- `jupyter lab` → 打开 Notebook

以上全部在命令行里敲。图形界面能做，但命令行**更快、更可复现、比赛时不出意外**。

**最低要求**：会用 VS Code 内置终端，能在里面敲命令就行。

## 1.3 命令行基础速查

### 进入和离开

```bash
cd "文件夹路径"    # 进入目录
cd ..             # 退回上一级
cd ~              # 回到用户目录
pwd               # 显示当前所在目录（Windows 上没用，但知道就行）
```

### 查看文件

```bash
ls                # 列出当前目录文件
ls -la            # 列出详细信息（含隐藏文件）
dir               # Windows 风格，跟 ls 差不多
```

### 文件操作

```bash
mkdir 文件夹名     # 创建文件夹
rm 文件名          # 删除文件（⚠️ 不可恢复）
rm -r 文件夹名     # 删除文件夹及其内容
cp 源文件 目标文件  # 复制
mv 源文件 目标文件  # 移动/重命名
```

### Python 相关

```bash
python --version          # 查看 Python 版本
pip install 包名          # 安装 Python 包
pip list                  # 列出已安装的包
jupyter lab               # 启动 Jupyter
```

### VS Code 终端小技巧

- `↑` 键 → 翻出上一条命令
- `Tab` 键 → 自动补全文件名
- `Ctrl + C` → 强制终止当前运行的命令
- 选中路径拖动到终端 → 自动粘贴路径

## 1.4 Python 环境

### 是什么

 Python 环境，用于承载项目需要的一些工具，依赖项。通常有venv虚拟环境和conda环境

### venv虚拟环境
每个venv是伴随项目而生的，在项目文件夹里才能调用位于venv中安装的工具。

**CMD终端**
```bash
venv\Scripts\activate.bat       #进入vene环境
```
**Powershell**
```bash
python -m venv .venv            #创建虚拟环境
.venv\Scripts\activate.ps1      #进入vene环境
```
**Mac**
```bash
source venv/Scripts/activate       #进入vene环境
```
**注意**：很多打开安装工具时都是直接打开终端直接安装，这样工具都是安装在系统环境里而没有起到环境隔离作用，故而激活环境在安装工具这一步时很有必要的。



### conda环境
conda环境是由conda这个环境管理器所管理的环境和总称，里面有着各种各样事先准备的环境，可以在任意项目的终端里用conda相关命令激活对应环境，从而来使用。conda环境默认不存放在项目文件夹

```bash
conda activate "环境名"  #激活环境
```
```bash
conda deactivate #退出环境
```
