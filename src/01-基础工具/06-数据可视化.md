## 6.1 核心原则

1. **标题要完整** —— 不是 "结果图"，是 "不同 α 值下目标函数值随迭代次数的变化"
2. **坐标轴有标签和单位** —— `xlabel('迭代次数')` 不是 `xlabel('x')`
3. **多条曲线加图例** —— `legend('α=0.1', 'α=0.3', 'α=0.5')`
4. **颜色要区分度高** —— 不用默认配色也没关系，但要看得清
5. **导出高清图** —— 论文里插图至少 300 dpi，截图糊一片是大忌

## 6.2 Python：Matplotlib 基础

```python
import matplotlib.pyplot as plt
import numpy as np

# 基本线图
x = np.linspace(0, 2*np.pi, 200)
plt.figure(figsize=(8, 5))             # 设置图片尺寸
plt.plot(x, np.sin(x), 'b-', linewidth=1.5, label='sin')
plt.plot(x, np.cos(x), 'r--', linewidth=1.5, label='cos')
plt.xlabel('x')
plt.ylabel('函数值')
plt.title('正弦与余弦函数')
plt.legend()
plt.grid(True, alpha=0.3)              # 淡色网格
plt.tight_layout()                     # 自动调整边距
plt.savefig('sin_cos.png', dpi=300)    # 保存高清图
plt.show()
```

## 6.4 配色建议

```python
# 方案 1：用 Matplotlib 自带 colormap（最省事）
cmap = plt.cm.viridis    # 默认，色盲友好
cmap = plt.cm.plasma     # 鲜艳
cmap = plt.cm.RdBu       # 红-蓝渐变，适合热力图
cmap = plt.cm.coolwarm   # 冷-暖对比

# 方案 2：自定义色板（从 ColorBrewer 选）
colors = ['#1f77b4', '#ff7f0e', '#2ca02c', '#d62728', '#9467bd']

# 方案 3：用 Seaborn 提升默认颜值（一行代码）
import seaborn as sns
sns.set_style('whitegrid')
sns.set_palette('husl')
```

## 6.7 常见坑

- ⚠️ 坐标轴不从 0 开始？论文里有时可以，但柱状图必须从 0 开始，否则视觉误导
- ⚠️ 3D 图看起来炫，但很多是"垃圾图"——角度不好啥都看不清，不如 2D + 颜色维度
- ⚠️ 饼图尽量别用，人眼不擅长比较角度，柱状图永远比饼图好读
- ⚠️ 保存前一定 `tight_layout()`，不然标签被切掉
- ⚠️ 中文字体问题：Python 默认不显示中文，解决方案：
  ```python
  plt.rcParams['font.sans-serif'] = ['SimHei']  # 黑体
  plt.rcParams['axes.unicode_minus'] = False    # 负号正常显示
  ```
