# 第四章 模型假设及数据准备

## 0. 本章承接与学习重点

问题分析解决“这道题往哪里建模”，接下来就要把模型边界和数据基础搭好。模型假设和数据准备看似是论文格式部分，其实决定了后面模型能不能成立。

这一章不能只按论文写作课来写，因为各专题课都在提醒我：不同模型对假设和数据的要求完全不同。

- 刘磊老师和李金沙老师都强调，假设要合理、简明、关键，不能罗列无关紧要的假设。
- 卢楠老师提醒，无效假设要删除，比如“数据真实可靠、计算无误差”这类空话。
- 唐厚俭老师讲建模假设和 2017A 题时给我的启发是：工程建模不是追求绝对精确，而是在有限信息、有限成本和噪声干扰下找到稳定好用的近似。
- 杨雨茜老师的插值与拟合课提醒我，数据是否含噪声会直接影响模型选择：插值默认点精确，拟合承认误差。
- 张朝辉老师的智能优化课提醒我，数据处理时要看关联性、缺失、噪声和归一化，尤其归一化对算法很重要。
- 陈华老师的机器学习材料预测课提醒我，数据集构建本身就是模型能力的一部分，训练数据、标签质量和泛化范围都要说明。

所以这一章的核心是：

```text
假设要支撑模型，数据要支撑计算。
```

## 1. 模型假设的作用

### 1.1 假设是合理简化

刘磊老师讲过，合理假设的作用是简化问题、明确问题、限定模型适用范围。

我的理解是：假设不是为了让论文显得正式，而是为了说明：

```text
我在哪些前提下，把复杂现实问题压缩成可以处理的数学问题。
```

例如 2024B 题中，如果不假设检测结果准确，就要考虑误判率和漏判率，模型会复杂很多。比赛时间有限时，可以先假设检测无误判，但要知道这是模型局限。

### 1.2 假设要和方法匹配

不同方法需要不同假设。

| 方法或模型 | 常见前提 |
|---|---|
| 二项分布抽样 | 每次检测结果为合格/不合格，同类产品次品率相同 |
| 最小二乘拟合 | 数据存在噪声，残差平方和可作为误差准则 |
| 插值 | 数据点较可信，需要曲线通过节点 |
| 线性规划 | 目标和约束近似线性，变量范围明确 |
| 图模型 | 对象和关系可以抽象为节点和边 |
| 机器学习 | 训练数据能代表预测场景，标签可靠 |
| 智能优化 | 目标函数可计算，解可以编码，约束可处理 |

这说明假设不能孤立写，要对应模型。

## 2. 什么是假设，什么不是假设

### 2.1 有效假设

有效假设要满足：

- 来自题目条件或建模需要；
- 能减少复杂度；
- 后面模型会用到；
- 不明显违背现实和题意。

例如：

```text
假设同一批次同类零配件的次品率相同，且各零配件合格状态相互独立。
```

这个假设支撑二项分布和合格概率计算。

再如：

```text
假设以单位成品为分析对象，各项成本和收益均按元/件计量。
```

这个假设支撑期望利润模型。

### 2.2 无效假设

无效假设常见表现：

```text
假设数据真实可靠。
假设计算无误差。
假设软件运行正常。
```

这些话没有进入模型，也不能提高可信度。

更好的写法应该更具体：

```text
假设检测过程不考虑误判和漏判，检测结果能准确反映样品是否合格。
```

这至少对应检测模型。

### 2.3 工程近似假设

唐厚俭老师讲 2017A 题时，我印象比较深的是工程建模思维：好的模型不是数学上绝对精确，而是在有限信息下足够稳定、可用、可解释。

所以有些假设不是“真理”，而是工程近似。

例如：

- 用二次函数近似实际关系；
- 用少量标定点拟合参数；
- 忽略非主要约束；
- 把复杂过程分阶段处理；
- 用区间估计替代真实参数。

这些都可以，但必须说明为什么这样简化不会破坏主要结论。

### 2.4 假设要分层写

我以前写假设容易平铺直叙，十几条假设看起来一样重要。但真正建模时，假设应该分层。

| 假设层级 | 作用 | 例子 | 写作重点 |
|---|---|---|---|
| 核心假设 | 支撑模型成立，不能轻易删 | 零配件合格状态相互独立 | 要说明为什么可接受，后文必须用到 |
| 简化假设 | 降低复杂度，可能影响精度 | 忽略检测误判和漏判 | 要在评价与改进中承认局限 |
| 计算假设 | 为了求解方便 | 将复杂成本视为固定单位成本 | 要说明单位和适用范围 |
| 边界假设 | 限定模型适用场景 | 只考虑题目给定生产流程，不考虑新增工序 | 要说明模型不覆盖什么情况 |

这样分层以后，假设就不会像套话。核心假设如果不成立，模型会变；简化假设如果放松，模型会更复杂但不一定推翻结论。

### 2.5 假设要能被后文接住

一条假设写出来后，我要问三件事：

```text
它支撑了哪个公式？
它简化了哪个现实过程？
它的风险会不会在评价或改进里讨论？
```

以 2024B 题为例：

```text
假设检测过程不考虑误判和漏判。
```

这条假设支撑问题二中的检测决策模型，因为被检测出的不合格品会被视为确定不合格。但它也带来局限：现实检测可能有误判和漏判。因此在模型改进中可以写“进一步可引入误检率和漏检率，修正检测后的条件概率”。

再如：

```text
假设各零配件合格状态相互独立。
```

这条假设支撑成品合格概率的乘法计算。如果同一批次零配件存在相关质量波动，模型会低估或高估整体风险，后续可用相关结构或批次随机效应改进。

我的提醒：假设不是写完就结束，而是要在“模型建立”和“模型评价”里都能看到它的影子。


## 3. 数据准备的核心问题

### 3.1 数据不是直接拿来用

张朝辉老师在论文写作部分提醒，数据处理首先要看数据元素之间的关联性，然后看缺失、噪声、是否需要归一化。

我现在整理成四个问题：

```text
数据是否完整？
数据是否有噪声？
数据是否需要统一单位或量纲？
数据是否适合当前模型？
```

### 3.2 从插值与拟合课看数据准备

杨雨茜老师讲插值和拟合时的区分非常重要：

- 插值：严格通过数据点，假设数据点精确。
- 拟合：不要求通过每个点，承认数据含噪声，追求整体趋势。

这对数据准备的启发是：

- 如果数据是传感器或实验观测值，不能默认无误差；
- 如果要补缺失值，可以考虑插值，但要注意插值区间和节点稳定性；
- 如果要找规律，应先画散点图，再决定拟合函数类型；
- 如果节点很多，不宜盲目高次插值，避免龙格现象。

### 3.3 从机器学习课看数据准备

陈华老师的机器学习材料预测课中，数据集构建、训练数据、标签、泛化能力是核心。这迁移到数模论文中，就是：如果用了数据驱动方法，不能只说“用机器学习预测”。还要说清：

- 数据集来源；
- 输入特征；
- 输出标签；
- 训练集和测试集划分；
- 是否标准化；
- 模型泛化到什么范围；
- 误差如何评价。

即使本章主题不是机器学习，也要有这种数据意识。

## 4. 2024B 题中的假设和数据准备

### 4.1 质量参数假设

```text
假设同类零配件在同一批次中具有相同次品率，且合格状态相互独立。
```

作用：支撑样本次品数分布和合格概率计算。

```text
问题四中，题目给出的次品率视为抽样估计值，真实次品率存在一定不确定性。
```

作用：支撑置信区间或贝叶斯修正。

### 4.2 检测与拆解假设

```text
假设检测结果准确，不考虑误判和漏判。
```

作用：简化检测环节。

```text
已检测合格的零配件拆解后不重复检测；未检测零配件拆解后需根据条件概率重新判断其合格状态。
```

作用：对应张胜利老师讲问题二时强调的检测记录问题。

### 4.3 成本收益数据准备

2024B 题表格中的参数可以分为：

| 类型 | 数据 | 用途 |
|---|---|---|
| 质量参数 | 零配件、半成品、成品次品率 | 计算合格概率和风险 |
| 成本参数 | 购买单价、检测成本、装配成本 | 构成总成本 |
| 收益参数 | 成品售价 | 构成收入 |
| 损失参数 | 调换损失、拆解费用 | 构成风险成本和返工成本 |
| 抽样参数 | 样本量、样本次品数、信度 | 构成抽样判决和参数修正 |

数据准备时要统一单位为元/件，概率统一写成 0 到 1 之间的小数。

### 4.4 问题四的数据修正

问题四不能直接把题目次品率当真实值用。

可以准备：

- 抽样样本量；
- 样本次品数；
- 样本次品率；
- 置信水平；
- 修正后的次品率区间；
- 修正前后策略对比数据。

这体现的是从“确定参数”到“估计参数”的转变。

## 5. 不同专题课对假设的迁移

### 5.1 优化课：约束能不能简化

穆学文老师讲最优化模型时提到，一般模型简化包括将离散变量连续化、非线性函数线性化、删除非主要约束等。

我的理解：这些简化都可以成为假设，但要谨慎。

例如把整数变量松弛为连续变量，就要说明最后如何回到整数方案；删除非主要约束，就要说明它确实不影响核心结果。

### 5.2 图优化课：对象关系是否完整

如果用图模型，假设要说明节点和边如何定义。

例如：

```text
假设生产流程中的零配件、半成品和成品可抽象为节点，装配关系可抽象为有向边。
```

这个假设能支撑流程图或图模型。

### 5.3 微分方程课：初值和参数是否明确

董灏老师的微分方程数值方法课提醒我，若建立动态模型，初值、参数和步长会影响求解。写动态模型时，数据准备不能只给方程，还要准备：

- 初始条件；
- 参数值；
- 时间区间；
- 数值步长；
- 误差控制方式。

### 5.4 机器学习课：训练分布是否代表应用场景

如果用机器学习预测，假设里要说明训练数据和预测对象之间的关系。

例如：

```text
假设训练数据覆盖了预测场景中的主要特征分布，模型可以在该范围内进行预测。
```

如果预测超出训练分布，就要在模型不足中说明风险。

## 6. 常见错误与修改方向

### 6.1 假设空泛

错误：

```text
假设数据真实可靠。
```

修改：

```text
假设检测结果不存在误判和漏判，检测出的不合格零配件不进入后续装配流程。
```

### 6.2 数据只搬表，不分类

错误：把题目表格完整复制，却不说明哪些数据进入哪个模型。

修改：按质量、成本、收益、损失、抽样参数分类。

### 6.3 不考虑数据噪声

错误：所有观测数据都当作精确点处理。

修改：先判断是插值问题还是拟合问题；对噪声数据考虑拟合、残差和异常值。

### 6.4 忽略归一化

张朝辉老师提醒归一化非常重要。尤其是评价、机器学习、智能优化中，不同量纲直接进入模型会导致某些指标支配结果。

修改：说明是否做归一化、标准化或量纲统一。

### 6.5 假设和后文公式脱节

错误：假设写了很多，但后面公式完全用不到。

修改：每条假设都对应一个模型步骤、公式或约束。

## 7. 本章自查清单

- 假设是否来自题目条件、模型需要或专题方法要求？
- 是否删除了无效假设？
- 是否说明了关键简化的合理性？
- 数据是否分类整理？
- 单位和量纲是否统一？
- 数据是否有缺失、异常、噪声？
- 需要插值还是拟合，理由是否清楚？
- 是否需要归一化？
- 如果使用机器学习，训练集、标签和泛化范围是否说明？
- 如果使用动态模型，初值、参数、步长是否准备？

## 8. 本章总结

模型假设和数据准备不是论文格式，而是建模基础。

我现在的理解是：

```text
假设 = 模型成立的边界
数据准备 = 模型计算的入口
```

这一章必须吸收专题课的思想：优化模型要有变量、约束和目标；图模型要有对象和关系；拟合模型要承认噪声；动态模型要有初值和步长；机器学习模型要有训练数据和泛化范围。只有这样，假设和数据才不是空泛文字。
