# 第五章 符号说明

## 0. 本章承接与学习重点

符号说明这一章表面上很小，实际很容易暴露建模是否真的清楚。前面的问题分析和假设写得再好，如果符号乱，后面的公式就会像临时拼出来的。

这章我重修时换了一个理解：符号说明不是“把公式里的字母列出来”，而是“提前告诉评阅人我这篇论文的数学对象是什么”。

这几节课给我的提醒分别是：

- 卢楠老师的论文写作课提醒我：符号说明要放在模型建立之前，表里出现的符号要和正文公式完全一致。
- 穆学文老师和杨国平老师的优化课提醒我：优化模型里至少要分清决策变量、参数、目标函数和约束条件。
- 龚育冬老师的图上优化课提醒我：图模型符号必须先定义节点集、边集、边权，否则后面的路径、流量、匹配都没有落点。
- 杨雨茜老师的插值拟合课提醒我：数据点、观测值、拟合值、残差不能混用，尤其要区分“真实值”和“模型算出来的值”。
- 董灏老师的数值方法课提醒我：动态模型不能只定义状态变量，还要定义时间、步长、初值和数值近似量。
- 张朝辉老师的智能优化课提醒我：算法变量和问题变量不是一回事，粒子位置、适应度、迭代次数这些也要交代。

我这一章要解决的问题是：

> 怎样写符号说明，才能让后面的公式看起来是自然建立出来的，而不是突然冒出来的？

## 1. 符号说明不是装饰

符号说明有三个作用。

第一，它让公式可读。比如正文里写 $x_i \in \{0,1\}$，评阅人需要知道 $x_i$ 是“第 $i$ 个零配件是否检测”，而不是某个抽象变量。

第二，它让模型边界清楚。比如 $p_i$ 是“第 $i$ 类零配件的次品率”，那它到底是题目给定的标称值、抽样估计值，还是贝叶斯修正后的后验均值？如果不写清楚，问题二和问题四就会混在一起。

第三，它让单位和量纲提前统一。成本、概率、数量、时间、距离不能随便进入一个公式。符号表中写单位，能逼自己检查公式有没有量纲错误。

我现在给自己定一个规则：

```text
凡是进入目标函数、约束条件、概率公式、误差指标、算法流程的量，都应该能在符号表或正文第一次出现处找到定义。
```

## 2. 符号要按“模型结构”分组

符号说明最差的写法是按字母顺序乱列。更好的写法是按模型结构分组，因为评阅人读符号时，实际上是在预习后面的模型。

### 2.1 下标与集合先写

很多论文符号乱，是因为下标没先定义。

常见集合与下标：

| 符号 | 含义 | 单位或取值 |
|---|---|---|
| $i$ | 零配件、节点或样本编号 | $i=1,2,\ldots,n$ |
| $j$ | 工序、阶段或方案编号 | $j=1,2,\ldots,m$ |
| $t$ | 时间步或迭代步 | 秒、天、轮次等 |
| $V$ | 图的节点集合 | 无量纲集合 |
| $E$ | 图的边集合 | 无量纲集合 |
| $S$ | 可行方案集合 | 无量纲集合 |

注意：同一个 $i$ 不要一会儿表示零件，一会儿表示方案。如果确实需要两个编号，宁可写 $i$ 表示零件、$k$ 表示方案。

### 2.2 决策变量和参数要分开

优化课给我的最大提醒是：决策变量是“我能选的”，参数是“题目给定或估计出来的”。这两个不能混。

以 2024B 问题二为例：

| 类型 | 符号 | 含义 | 单位或取值 |
|---|---|---|---|
| 决策变量 | $x_i$ | 是否检测第 $i$ 个零配件 | 0 或 1 |
| 决策变量 | $y$ | 是否检测成品 | 0 或 1 |
| 决策变量 | $z$ | 是否拆解不合格成品 | 0 或 1 |
| 参数 | $p_i$ | 第 $i$ 个零配件次品率 | 概率，无量纲 |
| 参数 | $c_i$ | 第 $i$ 个零配件购买单价 | 元/件 |
| 参数 | $d_i$ | 第 $i$ 个零配件检测成本 | 元/件 |
| 参数 | $a$ | 装配成本 | 元/件 |
| 参数 | $s$ | 成品售价 | 元/件 |
| 参数 | $l$ | 调换损失 | 元/件 |

这里要注意：$x_i$、$y$、$z$ 是可以优化选择的；$p_i$、$c_i$、$d_i$ 是输入。问题四中 $p_i$ 可能由抽样估计得到，但它仍然不是决策变量，而是不确定参数。

### 2.3 目标函数里的量要能解释单位

如果目标函数是期望利润，可以写：

$$
\max E(\Pi)=E(R)-E(C)
$$

其中：

- $E(\Pi)$ 表示期望利润，单位为元；
- $E(R)$ 表示期望收入，单位为元；
- $E(C)$ 表示期望总成本，单位为元。

这个公式看起来简单，但它能检查一个问题：右边两项单位必须一致。如果把“概率”和“成本”直接相加，就说明模型有量纲错误。

我的提醒：符号表里不能只写“$C$ 表示成本”。要尽量写成“某过程的单位成本、总成本、期望成本”，否则后面很容易混。

## 3. 按专题模型补充符号

### 3.1 图模型符号

图模型要先定义图本身：

$$
G=(V,E,W)
$$

其中：

- $G$ 表示图结构，无量纲；
- $V$ 表示节点集合，节点可以是城市、工序、零配件、任务点；
- $E$ 表示边集合，边表示连接、转移、装配关系或可达关系；
- $W=(w_{ij})$ 表示边权矩阵，$w_{ij}$ 可以是距离、时间、成本或容量。

常见符号：

| 符号 | 含义 | 单位或取值 |
|---|---|---|
| $v_i$ | 第 $i$ 个节点 | 无量纲对象 |
| $e_{ij}$ | 节点 $i$ 到节点 $j$ 的边 | 有/无，或边对象 |
| $w_{ij}$ | 边 $e_{ij}$ 的权重 | km、min、元、件/小时等 |
| $P$ | 一条路径 | 节点序列 |
| $f_{ij}$ | 边 $e_{ij}$ 上的流量 | 件/小时、辆/小时等 |

龚育冬老师那节课让我意识到，图符号不是为了显得高级，而是为了避免“关系”说不清。比如生产装配流程可以把零配件和半成品看成节点，把装配关系看成有向边；如果这一层符号没定义，后文流程图和约束就会断开。

### 3.2 插值拟合符号

杨雨茜老师的插值拟合课里，一个非常关键的区分是：观测值不等于拟合值。

| 符号 | 含义 | 单位或取值 |
|---|---|---|
| $x_i$ | 第 $i$ 个自变量观测点 | 由题目决定，如年份、温度 |
| $y_i$ | 对应观测值 | 由指标决定，如销量、浓度 |
| $\hat{y}_i$ | 模型拟合值或预测值 | 与 $y_i$ 同单位 |
| $r_i$ | 残差，$r_i=y_i-\hat{y}_i$ | 与 $y_i$ 同单位 |
| $Q$ | 残差平方和，$Q=\sum r_i^2$ | $y$ 单位的平方 |
| $R^2$ | 拟合优度 | 无量纲，通常在 0 到 1 附近 |

如果做插值，符号重点是节点和插值函数；如果做拟合，符号重点是参数、残差和误差指标。

我的提醒：如果论文里 $y_i$、$\hat{y}_i$、$r_i$ 没分开，就很难写出像样的误差分析。

### 3.3 动态模型和数值方法符号

董灏老师的数值方法课提醒我，动态模型至少要有时间、状态、参数、初值和步长。

| 符号 | 含义 | 单位或取值 |
|---|---|---|
| $t$ | 连续时间 | 秒、天、年等 |
| $t_k$ | 第 $k$ 个离散时间点 | $t_k=t_0+kh$ |
| $h$ | 数值求解步长 | 与时间同单位 |
| $X(t)$ | 时刻 $t$ 的状态变量 | 与研究对象有关 |
| $X_0$ | 初始状态 | 与 $X$ 同单位 |
| $\theta$ | 模型参数向量 | 视参数而定 |
| $\hat{X}_k$ | 数值近似解 | 与 $X$ 同单位 |

常见方程写成：

$$
\frac{dX}{dt}=F(X,t,\theta),\quad X(t_0)=X_0
$$

符号表至少要让人知道 $X$ 是什么状态，$\theta$ 是哪些参数，$h$ 为什么取这个值。否则只写 `ode45` 或 `Runge-Kutta`，评阅人看不到模型本身。

### 3.4 智能优化和机器学习符号

张朝辉老师和陈华老师的课都提醒我：算法符号不能和问题符号搅在一起。

以粒子群为例：

| 符号 | 含义 | 单位或取值 |
|---|---|---|
| $N$ | 粒子数量 | 正整数 |
| $K$ | 最大迭代次数 | 正整数 |
| $X_i^k$ | 第 $k$ 轮第 $i$ 个粒子的位置 | 决策向量 |
| $V_i^k$ | 第 $k$ 轮第 $i$ 个粒子的速度 | 与位置变化量同单位 |
| $pbest_i$ | 第 $i$ 个粒子的历史最优位置 | 决策向量 |
| $gbest$ | 全局最优位置 | 决策向量 |
| $F(X)$ | 适应度函数 | 通常与目标函数相关 |

以机器学习为例：

| 符号 | 含义 | 单位或取值 |
|---|---|---|
| $\mathbf{x}_i$ | 第 $i$ 个样本的特征向量 | 各特征单位可能不同 |
| $y_i$ | 第 $i$ 个样本标签 | 分类标签或连续值 |
| $\hat{y}_i$ | 模型预测值 | 与 $y_i$ 同类型 |
| $L$ | 损失函数 | 由任务决定 |
| $D_{train}$ | 训练集 | 样本集合 |
| $D_{test}$ | 测试集 | 样本集合 |

我的提醒：机器学习符号必须体现“训练”和“测试”分开，否则后面说泛化能力就没有依据。

## 4. 2024B 题符号说明示例

如果我写 2024B 题，可以按下面几组来组织，而不是把所有字母混在一张大表里。

### 4.1 抽样检验部分

| 符号 | 含义 | 单位或取值 |
|---|---|---|
| $n$ | 抽样数量 | 件 |
| $k$ | 样本中检测出的次品数 | 件 |
| $p_0$ | 标称次品率 | 概率 |
| $p$ | 实际次品率 | 概率 |
| $\alpha$ | 拒收判断的显著性水平 | 概率 |
| $\beta$ | 接收判断的错误概率 | 概率 |

这里 $p_0$ 和 $p$ 一定要分开。$p_0$ 是题目给的标称值，$p$ 是未知真实值或估计值。

### 4.2 生产决策部分

| 符号 | 含义 | 单位或取值 |
|---|---|---|
| $x_i$ | 是否检测第 $i$ 个零配件 | 0 或 1 |
| $y$ | 是否检测成品 | 0 或 1 |
| $z$ | 是否拆解不合格成品 | 0 或 1 |
| $C(x,y,z)$ | 策略 $(x,y,z)$ 下的期望成本 | 元 |
| $\Pi(x,y,z)$ | 策略 $(x,y,z)$ 下的期望利润 | 元 |
| $q(x,y)$ | 成品在策略 $(x,y)$ 下的不合格概率 | 概率 |

这里要注意，$q(x,y)$ 不是题目直接给的次品率，而是检测策略改变后推出来的概率。这个符号如果写清楚，后面就能自然解释为什么检测会改变期望利润。

### 4.3 多工序与算法部分

| 符号 | 含义 | 单位或取值 |
|---|---|---|
| $X$ | 全流程检测与拆解决策向量 | 0-1 向量 |
| $X_r$ | 第 $r$ 个候选策略 | 0-1 向量 |
| $F(X)$ | 策略 $X$ 的适应度函数 | 元或无量纲 |
| $K$ | 最大迭代次数 | 次 |
| $G=(V,E)$ | 多工序装配关系图 | 图结构 |

如果问题三用粒子群，$X$ 既是生产策略，也是粒子位置编码，这一点要在正文里说明。否则读者会以为算法符号和生产符号是两套东西。

## 5. 常见问题和修改方向

### 5.1 符号表像字母词典

差的写法：

```text
x 表示变量，p 表示概率，C 表示成本。
```

问题是太粗。应该改成：

```text
$x_i$ 表示是否检测第 $i$ 个零配件；$p_i$ 表示第 $i$ 个零配件的次品率；$C_d$ 表示单位检测成本。
```

### 5.2 决策变量和参数混用

比如把“次品率是否为 10%”写成变量，其实这是参数估计问题，不是决策变量。真正可决策的是是否检测、是否拆解、抽样多少件。

### 5.3 单位缺失

成本是元/件还是总元，时间是小时还是天，概率是百分数还是小数，都要写清。单位不清，公式结果很可能解释错。

### 5.4 公式里突然出现新符号

这是最常见扣分点之一。我的检查方法是：从模型建立章节任选一个公式，把每个字母圈出来，看能不能在符号表或公式下方解释中找到。

## 6. 我的符号设计流程

我现在写符号说明会按这个顺序：

1. 先列集合和下标。
2. 再列决策变量。
3. 再列题目参数和估计参数。
4. 再列中间变量，如概率、成本、残差、路径长度。
5. 最后列算法变量，如迭代次数、粒子位置、损失函数。

写完后再反向检查：公式里的符号是否都出现，符号表里的符号是否都在正文用到。没用到的删掉，没定义的补上。

## 7. 本章总结

符号说明不是排版任务，而是模型结构的预告。

我现在的理解是：

```text
符号说明 = 把变量、参数、单位、模型对象提前摆清楚
```

如果符号说明写得好，后面的模型建立会顺很多；如果符号说明写得乱，说明我自己可能还没分清“什么是我能决定的，什么是题目给定的，什么是模型算出来的”。
