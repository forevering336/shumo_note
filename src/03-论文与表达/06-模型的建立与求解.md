# 第六章 模型的建立与求解

## 0. 本章承接与学习重点

前面几章已经把题目分析清楚、假设立好、符号统一。第六章是论文最核心的部分：把问题真正写成模型，并给出求解过程。

这一章必须综合多门专题课，而不能只照论文写作课：

- 穆学文老师的优化课给出优化模型三要素：决策变量和参数、约束条件、目标函数。
- 杨国平老师的连续优化与整数优化课提醒我，连续变量和整数变量对应不同求解方法，不能混着写。
- 龚育冬老师的图上优化课提醒我，图结构可以让离散问题可表达、可计算、可展示。
- 杨雨茜老师的插值与拟合课提醒我，数据模型要写清误差准则，比如最小二乘的残差平方和。
- 董灏老师的微分方程数值方法课提醒我，很多模型没有解析解，必须写清数值方法、步长和误差控制。
- 张朝辉老师的智能优化课提醒我，复杂算法要说明编码方式、适应度函数、参数设置和收敛情况。
- 张胜利老师的 2024B 题讲评课给了生产决策题的完整示范：抽样检验、0-1规划、粒子群、贝叶斯修正如何逐问推进。

所以这一章的重点是：

```text
模型建立要有数学结构，模型求解要有算法过程。
```

## 1. 模型建立的底层结构

### 1.1 优化模型三要素

穆学文老师讲最优化模型时提到，建立最优化问题数学模型要抓：

1. 决策变量和参数；
2. 约束或限制条件；
3. 目标函数。

这几乎可以作为所有优化类论文的骨架。

例如 2024B 问题二：

- 决策变量：是否检测零配件、是否检测成品、是否拆解不合格品。
- 参数：次品率、购买单价、检测成本、装配成本、售价、调换损失、拆解费用。
- 约束：生产流程、检测规则、拆解规则。
- 目标函数：期望利润最大或期望成本最小。

只要这四件事写清楚，模型就有基本形状。

### 1.2 模型不是公式堆砌

卢楠老师提醒，关键公式要有文字解释，不能直接丢公式。

每个模型最好按下面顺序写：

```text
建模思路
→ 变量定义
→ 目标函数
→ 约束条件
→ 求解方法
→ 输出结果
```

## 2. 不同类型模型怎么写

### 2.1 连续优化和整数优化

连续优化中变量可以连续取值，整数优化中变量必须是整数或 0-1。

写作时要说明：

- 变量类型；
- 目标函数是否线性；
- 约束是否线性；
- 是否可用线性规划、整数规划、非线性规划；
- 如果做了松弛或线性化，要说明理由。

2024B 中“是否检测”显然是 0-1 决策，不能写成连续变量。

### 2.2 图模型

如果用图模型，要写清：

```text
节点是什么？
边是什么？
边权表示什么？
路径或流量代表什么？
优化目标是什么？
```

例如多工序生产结构可以画成装配关系图；路径规划题可以写最短路或车辆路径模型；任务调度题可以写有向无环图和先后约束。

图模型的优势是表达清楚，尤其适合复杂关系。

### 2.3 插值与拟合模型

如果是插值，要说明：

- 已知节点；
- 插值函数；
- 插值条件；
- 为什么可以认为节点可靠；
- 是否存在高次振荡风险。

如果是拟合，要说明：

- 拟合函数形式；
- 残差定义；
- 误差准则；
- 参数求解方法；
- 拟合优度或误差指标。

杨雨茜老师讲最小二乘时，核心是最小化残差平方和：

$$
Q=\sum_{i=1}^{n}[S(x_i)-y_i]^2
$$

这类公式在论文里不能只写，还要说明 $S(x_i)$ 是拟合值，$y_i$ 是观测值，$Q$ 是残差平方和。

### 2.4 微分方程和数值求解模型

如果模型是动态变化过程，要写：

- 状态变量；
- 微分方程；
- 初始条件；
- 参数含义；
- 是否有解析解；
- 若无解析解，用什么数值方法；
- 步长和误差如何控制。

董灏老师的数值方法课提醒我，数值求解不是黑箱，步长和稳定性会影响结果。论文中不能只写“用 ode45 求解”，还要说明求解区间、初值和误差控制。

### 2.5 智能优化模型

如果采用 GA、SA、PSO 等算法，要写清：

- 解如何编码；
- 适应度函数是什么；
- 约束如何处理；
- 参数如何设置；
- 迭代终止条件；
- 是否多次运行；
- 是否和简单方法对比验证。

张朝辉老师的算法选型表提醒我：路径规划、资源分配、调度、参数估计、动态决策对应的算法不同。不能看到“优化”就都用粒子群。

## 3. 2024B 题逐问建模示例

### 3.1 问题一：抽样检验模型

设样本中次品数为 $X$。若批量较大，可用二项分布近似：

$$
X\sim B(n,p)
$$

其中：

- $n$ 为样本量，单位件；
- $p$ 为真实次品率；
- $X$ 为样本中次品数。

目标是找到最小 $n$ 和阈值 $c$，使判决规则满足信度要求。

求解步骤：

1. 设定标称次品率和信度；
2. 遍历样本量 $n$；
3. 对每个 $n$ 遍历最大允许次品数 $c$；
4. 计算接收或拒收概率；
5. 找到满足条件的最小样本量。

### 3.2 问题二：0-1 整数规划或枚举模型

设：

- $x_1,x_2$ 表示是否检测零配件；
- $y$ 表示是否检测成品；
- $z$ 表示是否拆解不合格品。

变量满足：

$$
x_1,x_2,y,z\in\{0,1\}
$$

目标函数可写为：

$$
\max \Pi = R-C
$$

其中 $R$ 为期望收入，$C$ 为期望成本，单位均为元/件。

由于变量较少，可枚举所有策略，逐一计算期望利润。这里用枚举不是低级，而是因为小规模 0-1 决策下枚举能保证全局最优。

### 3.3 问题三：多工序组合优化模型

问题三将问题二扩展到更多零配件和半成品。设决策向量：

$$
\mathbf{x}=(x_1,x_2,\dots,x_m),\quad x_i\in\{0,1\}
$$

其中每个 $x_i$ 表示某一环节是否检测或拆解。

目标函数仍是：

$$
\max \Pi(\mathbf{x})
$$

但搜索空间变为 $2^m$，当 $m$ 增大时完全枚举成本较高。

可以采用粒子群或遗传算法求解，但必须写清：

- 二进制编码方式；
- 适应度函数为期望利润；
- 约束如何处理；
- 粒子数量、迭代次数；
- 结果如何验证。

### 3.4 问题四：参数不确定性修正模型

问题四中，次品率来自抽样检测，真实次品率未知。

建模思路：

```text
抽样数据 → 次品率区间或后验分布 → 修正模型参数 → 重新求解问题二和三 → 比较策略变化
```

可以用置信区间或贝叶斯方法。若采用贝叶斯修正，要说明先验、似然和后验如何对应抽样检测过程。

## 4. 模型求解怎么写

### 4.1 不要只写软件

错误写法：

```text
利用 Python 求解模型。
```

更好的写法：

```text
对问题二，本文枚举全部0-1策略组合，计算每种策略下的期望利润，并选择利润最大者作为最优方案；程序使用 Python 实现。
```

软件是工具，算法才是方法。

### 4.2 复杂算法要写流程

张朝辉老师提醒，复杂算法可以画流程图或写伪代码。

粒子群算法可写：

```text
初始化粒子位置和速度；
计算每个粒子的适应度；
更新个体最优和全局最优；
根据速度和位置更新规则生成新解；
重复迭代直到达到最大迭代次数或收敛条件。
```

### 4.3 结果要和题目输出对应

求解结果必须回答题目。

2024B 中：

- 问题一输出样本量和判决规则；
- 问题二输出每种情形的决策方案和指标结果；
- 问题三输出多工序完整决策方案；
- 问题四输出修正后问题二、三的决策结果和误差影响。

### 4.4 求解过程要写到可复现

我以前容易把“求解”写成一句软件说明，但现在觉得这不够。真正可复现的求解过程至少要包含：

- 输入：使用哪些数据和参数；
- 变量：求解对象是什么；
- 目标：评价一个解好坏的函数是什么；
- 约束：哪些解不允许出现；
- 算法：怎样从候选解找到最终解；
- 参数：算法本身有哪些设置；
- 输出：最后输出什么表、什么图、什么决策。

可以整理成下面这种写法：

```text
输入题目给定的次品率、检测成本、装配成本、售价、调换损失和拆解费用；
枚举所有检测与拆解决策向量 X；
对每个 X 计算成品合格概率、期望收入、检测成本、装配成本、拆解成本和调换损失；
剔除不满足工艺约束的方案；
以期望利润最大为准则选择最优方案；
输出最优决策向量、对应期望利润和各成本分项。
```

这样写比“利用 Python 求解”强很多，因为评阅人能看出我每一步在算什么。

### 4.5 MATLAB 或 Python 实现要点

这一章不需要贴完整代码，但要知道实现时抓哪些函数。

| 模型类型 | MATLAB 实现要点 | Python 实现要点 |
|---|---|---|
| 0-1 枚举 | `dec2bin`、循环、矩阵运算 | `itertools.product`、`numpy`、`pandas` |
| 线性/整数规划 | `linprog`、`intlinprog` | `scipy.optimize.linprog`、`pulp`、`ortools` |
| 图模型 | `graph`、`digraph`、`shortestpath` | `networkx`、`scipy.sparse.csgraph` |
| 插值拟合 | `interp1`、`polyfit`、`lsqcurvefit` | `scipy.interpolate`、`numpy.polyfit`、`scipy.optimize.curve_fit` |
| 微分方程 | `ode45`、`ode15s` | `scipy.integrate.solve_ivp` |
| 智能优化 | 自写 PSO/GA 或工具箱 | `pyswarms`、`deap`、自写迭代 |
| 机器学习 | Statistics and Machine Learning Toolbox | `scikit-learn`、`xgboost`、`pytorch` |

我的提醒：论文里可以写实现工具，但不能让工具替代模型。比如用了 `intlinprog`，正文要先有整数规划模型；用了 `curve_fit`，正文要先有拟合函数和残差准则；用了 `networkx`，正文要先有节点、边和边权定义。
## 5. 常见错误与修改方向

### 5.1 模型缺少目标函数

优化题没有目标函数，就不是完整优化模型。

### 5.2 变量约束遗漏

0-1变量必须写 $x_i\in\{0,1\}$，概率必须写范围，成本一般非负。

### 5.3 公式没有来源

每个公式都要能回到题目条件、假设或已有方法。

### 5.4 算法和问题不匹配

小规模问题不一定需要智能优化；高维组合问题也不能简单穷举不解释计算量。

### 5.5 数值方法没有误差说明

微分方程、拟合、智能优化都要说明误差、收敛或稳定性。

## 6. 本章自查清单

- 是否写清变量、参数、约束和目标？
- 是否说明模型来自题目场景？
- 是否区分连续、整数、0-1变量？
- 是否需要图结构表达对象关系？
- 数据模型是否说明插值、拟合和误差准则？
- 动态模型是否说明初值、步长和数值方法？
- 智能优化是否说明编码、适应度、参数和收敛？
- 求解结果是否对应题目输出？
- 是否避免只写软件名？

## 7. 本章总结

模型建立与求解是专题课知识真正落地的地方。

我现在的理解是：

```text
模型建立 = 变量 + 约束 + 目标 + 结构
模型求解 = 算法 + 参数 + 过程 + 结果
```

这一章要把优化课、图模型课、插值拟合课、数值方法课、智能优化课都迁移进来。不同题型用不同表达方式，不能所有模型都写成同一种“建立模型并求解”。
