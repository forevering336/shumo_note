# 第二章 问题重述

## 0. 本章承接与学习重点

上一章学摘要时，我主要关注的是：怎样把一篇论文的模型、方法、结果和检验压缩给评阅老师看。第二章开始往正文推进，重点变成：怎样把赛题本身理解清楚，并用自己的话重述出来。

这一章仍然接着论文写作课来整理，但关注点和摘要不同：

- 刘磊老师讲问题重述时，重点是“不是题目的完整拷贝”，而是用自己的语言清楚简明地阐述背景、条件和要求。
- 卢楠老师讲问题重述时，强调逐问拆解，说明每一问拟采用的建模思路，不能大段复制原题。
- 李金沙老师在数模概论课中提醒，不能照搬原文，要把原问题转化成数学语言，并把阅卷老师引导到自己的思路中。
- 张胜利老师讲 2024B 题时，先从问题背景、数据说明、问题重述进入解题要点，这给了我一个很清楚的示范：重述不是抄题，而是为后面的分析和建模铺路。
- 其他专题课给我的补充是：问题重述不只看语言，还要看题目背后的模型类型。优化题要重述目标和约束，图论题要重述对象和关系，拟合题要重述数据与误差，动态题要重述状态变化，机器学习题要重述输入、标签和预测目标。

这一章我想解决的问题是：

> 问题重述到底是“换句话说题目”，还是“把题目拆成能建模的问题”？

我现在的判断是：问题重述不能只是改写原题，它应该完成两个动作：

1. 把题目背景、条件、要求用自己的话讲清楚。
2. 把每个小问背后的建模任务提前拆出来。

所以本章会围绕“怎么避免复制题目”和“怎么逐问拆解”来写。

## 1. 问题重述在论文中的作用

### 1.1 课堂中的原始要求

刘磊老师在论文写作课中讲到，问题重述不是题目的完整拷贝，而是要根据自己的理解，用自己的语言清楚简明地阐述背景、条件和要求。

卢楠老师在论文写作课中提醒，问题重述常见错误是大段复制题目原文，没有完成子问题拆解。更好的做法是逐问拆解，说明每一问拟采用的建模思路，并简单比较备选方法的优缺点。

李金沙老师在数模概论课中也强调，千万不要照搬原文，要把原问题用数学语言表达出来，并把阅卷老师引导到自己的思路中。

### 1.2 我的理解

我以前可能会觉得问题重述就是“把题目换个说法写一遍”。但听完这几节课后，我觉得这个理解不够。

问题重述真正要做的是：

```text
原始赛题语言
→ 我的理解语言
→ 可建模的问题语言
```

也就是说，问题重述不是复制题目，也不是提前写模型公式，而是把题目整理到“后面可以自然建模”的状态。

如果这一章写得好，后面的“问题分析、模型假设、符号说明、模型建立”都会更顺。如果问题重述只是照抄题目，后面建模就容易显得突然：读者不知道我为什么这样设变量，为什么这样建目标函数，也不知道每一问之间的关系。

## 2. 问题重述和摘要的区别

我需要先把“摘要”和“问题重述”区分开。

### 2.1 摘要的重点

摘要要回答：

- 论文解决了什么问题；
- 建立了什么模型；
- 用了什么方法；
- 得到了什么结果；
- 结果是否可靠。

摘要要有模型、算法、结果和检验，是全文成果的压缩。

### 2.2 问题重述的重点

问题重述主要回答：

- 题目背景是什么；
- 已知条件有哪些；
- 题目要求解决哪些任务；
- 每个小问之间有什么递进关系；
- 这些任务大致对应什么建模方向。

它不需要把最后结果写出来，也不需要展开公式推导。它的重点是“把问题说清楚”。

### 2.3 我的判断

摘要更像“结果导向”，问题重述更像“审题导向”。

```text
摘要：我最后做成了什么。
问题重述：我把题目理解成了什么。
```

如果摘要太像问题重述，就会缺少结果；如果问题重述太像摘要，就会过早写模型和结论，反而不自然。

## 3. 问题重述应该写什么

### 3.1 背景要简化

问题重述开头可以写背景，但不能把题目背景大段搬过来。

应该保留的是：

- 研究对象；
- 现实矛盾；
- 题目给出的关键情境；
- 为什么需要建模。

不应该写太多的是：

- 与建模无关的科普背景；
- 题目里很长的叙述性材料；
- 情绪化或宣传式表达；
- 没有进入后续模型的细节。

以 2024B 题为例，背景可以压缩成：

```text
某企业生产的电子成品由多个零配件装配而成，零配件、半成品和成品均可能存在次品。企业需要在检测成本、装配成本、退换损失和拆解费用之间进行权衡，从而制定合理的检测与拆解决策。
```

这句话保留了生产对象和核心矛盾，但没有逐字复制题目。

### 3.2 条件要筛选

题目中给出的条件很多，但问题重述不能把表格内容全抄一遍。更好的做法是把条件分类。

常见分类方式：

- 数据条件：题目给了哪些表、哪些参数。
- 决策条件：哪些量是我们可以选择的。
- 约束条件：哪些规则必须遵守。
- 目标条件：题目希望优化或判断什么。

以 2024B 题为例，条件可以整理为：

- 表 1 给出两种零配件和成品的次品率、成本、售价、调换损失和拆解费用。
- 表 2 将生产流程扩展到 8 种零配件、3 种半成品和成品。
- 企业可以选择是否检测零配件、是否检测成品、是否拆解不合格品。
- 若不合格品流入市场，企业需要承担调换损失。
- 问题四中次品率不再被视为真实已知，而是由抽样检测得到。

这样写比照抄题目更清楚，也更方便后面定义参数和决策变量。

### 3.3 要求要逐问拆解

卢楠老师课上特别强调要逐问拆解。我的理解是，国赛题通常不是几个独立小题，而是一步一步把问题加复杂。

问题重述时要把这种递进写出来：

```text
问题一：先解决基础判断或基础计算。
问题二：在给定条件下建立主要模型。
问题三：把模型推广到更复杂情形。
问题四：考虑不确定性、误差或现实约束后改进模型。
```

以 2024B 题为例：

- 问题一关注抽样检测方案，重点是用较少样本判断零配件批次是否满足标称次品率要求。
- 问题二关注给定次品率下的生产过程决策，重点是在检测、装配、拆解、退换之间权衡成本收益。
- 问题三把问题二推广到多工序、多零配件、多半成品的复杂流程。
- 问题四进一步考虑次品率由抽样估计得到，因此需要分析估计误差对问题二、三决策的影响。

这样重述之后，后面自然就能接到问题分析。

### 3.4 不同类型题目的重述侧重点

这一节也是我重修时补上的。因为问题重述如果只按写作课要求来写，容易停在“别抄题、逐问拆解”这一级；但真正比赛时，能不能重述好，取决于我有没有看出题目背后的模型类型。

#### 优化类题目

穆学文老师讲最优化模型时提醒，优化问题至少要有“可行方案”和“追求目标”，进一步要落到决策变量、约束条件和目标函数。杨国平老师讲连续优化与整数优化时，也把变量类型看得很重要。

所以优化类题目的重述重点是：

- 我能控制什么；
- 我想让什么最大或最小；
- 有哪些现实限制；
- 变量是连续的还是离散的；
- 多个目标之间是否冲突。

比如题目说“制定合理调度方案”，不能只重述为“求一个调度方案”。更像建模语言的写法是：

```text
该问要求在资源数量、作业顺序和时间窗口约束下，确定各任务的执行顺序与资源分配方案，使总完成时间或总成本尽可能小，因此可重述为带约束的调度优化问题。
```

我的理解：优化题重述的关键不是提前写目标函数，而是先把“谁可决策、受什么限制、追求什么”说清楚。

#### 图与网络类题目

龚育冬老师讲图上优化时，我记住的一条线是“对象—关系—约束”。只要题目里有道路、连接、通信、运输、匹配、路径、覆盖、流量，就要考虑能不能转成图。

这类题重述时要写清：

- 对象是什么，能不能作为节点；
- 对象之间的关系是什么，能不能作为边；
- 距离、费用、时间、容量能不能作为边权；
- 题目要求的是路径、连通、覆盖、分配还是流量。

例如：

```text
该问要求在道路连接和服务半径限制下安排巡检路线。可将各巡检点抽象为节点，将道路通行关系抽象为带权边，把路线设计重述为满足覆盖约束的路径优化问题。
```

我的理解：图论题的问题重述要让后面的节点集、边集、边权自然出现。

#### 数据拟合与预测类题目

杨雨茜老师讲插值与拟合时提醒，插值适合精确节点，拟合适合含噪声数据。这对问题重述很有用。

如果题目给的是历史观测数据、实验数据、时间序列或散点关系，重述时要分清：

- 是补全缺失点，还是预测未来趋势；
- 数据是否有噪声；
- 自变量和因变量分别是什么；
- 需要的是函数关系、趋势判断还是误差评价。

例如：

```text
该问要求根据已有观测数据刻画变量间变化关系，并预测后续取值。由于观测数据可能含有测量误差，可将其重述为参数拟合与趋势预测问题，而不是要求曲线严格通过每个数据点。
```

我的理解：这类题重述时如果没有提“误差”或“趋势”，后面突然使用最小二乘就会显得没有来由。

#### 动态过程类题目

董灏老师的微分方程数值方法课提醒我，动态问题要关注状态、时间、初值、参数和数值求解。

如果题目涉及传播、增长、衰减、运动、扩散、演化，问题重述时应该写清：

- 状态量随什么变量变化；
- 初始条件来自哪里；
- 变化规律可能由哪些参数控制；
- 要求的是短期预测、长期趋势、峰值还是稳定状态。

例如：

```text
该问关注系统状态随时间的演化规律，需要根据初始状态和历史观测估计关键参数，并预测未来一段时间内状态变量的变化趋势，因此可重述为动态过程建模与数值预测问题。
```

我的理解：动态题重述不能只说“预测变化”，要把“状态量随时间演化”点出来。

#### 决策与评价类题目

邹青松老师的决策模型课提醒我，决策问题要看信息条件：确定型、不确定型、风险型、多属性决策，不能全部写成简单排序。

如果题目要求“选择最佳方案、评价优劣、制定策略”，重述时要写清：

- 评价对象是谁；
- 指标有哪些；
- 指标正负向是否不同；
- 权重是否已知；
- 是否存在风险或不确定性。

例如：

```text
该问要求在多个评价指标共同影响下比较不同方案优劣。由于各指标量纲和方向不同，可将其重述为多指标综合评价与方案排序问题，并需要进一步确定指标标准化和权重计算方法。
```

我的理解：综合评价题重述时不能只写“评价某某水平”，要提前暴露指标、权重、排序这些关键词。

#### 机器学习与智能优化类题目

张朝辉老师的智能优化课和陈华老师的机器学习课提醒我，算法类题目要先看任务类型，而不是先想算法名。

这类题重述时要交代：

- 输入数据是什么；
- 输出目标是什么；
- 是分类、回归、聚类，还是序贯决策；
- 数据是否需要训练集和测试集；
- 结果怎样验证；
- 算法是否只是求解工具，而不是问题本身。

例如：

```text
该问要求根据历史样本预测材料性能，可将样本的组成、工艺和结构信息视为输入特征，将目标性能视为标签，重述为监督学习中的回归预测问题，并需通过测试集误差评价模型泛化能力。
```

我的理解：机器学习题的重述要避免一开头就说“使用神经网络”。先说清预测任务，再说模型选择才自然。
## 4. 问题重述不能写成什么样

### 4.1 不能大段复制原题

课堂里反复提醒，问题重述不是复制题目。直接复制有几个问题：

- 显得没有认真审题；
- 容易造成重复率问题；
- 不能体现自己的建模理解；
- 评阅老师看不到题目条件是怎样被转化成模型的。

差的写法：

```text
问题一：两个零配件标称值均不超过10%，在95%的信度下认定零配件次品率超过标称值，则拒收这批零配件；在90%的信度下认定零配件次品率不超过标称值，则接收这批零配件。
```

这个写法基本是在搬题目。

更好的写法：

```text
问题一要求在控制判断信度的前提下，设计尽可能少的抽样检测方案。核心是根据抽取样本中的次品数判断该批零配件的真实次品率是否超过标称水平，因此可将其重述为小样本统计判决和最小样本量设计问题。
```

这个写法把题目转成了建模语言：信度、样本次品数、真实次品率、统计判决、最小样本量。

### 4.2 不能过早写公式和结论

问题重述不是模型建立。这里不适合直接写完整目标函数、约束条件和最终结果。

不合适的写法：

```text
设 x1, x2, x3, x4 为0-1变量，建立最大利润函数 max P=...，最终得到最优策略为……。
```

这已经进入模型建立和求解了，不属于问题重述。

更合适的写法：

```text
问题二要求在已知零配件和成品次品率的条件下，对检测与拆解决策进行选择。由于每个检测或拆解动作都对应成本或收益变化，因此可将该问重述为以期望成本或期望利润为依据的离散决策问题。
```

这里点出建模方向，但不提前写完整模型。

### 4.3 不能写得太空

另一个极端是写得太空。

差的写法：

```text
本文需要分析生产过程中的相关问题，并给出合理方案。
```

这句话几乎没有信息量。

更好的写法：

```text
本文需要围绕生产过程中的质量检测与返工拆解决策，分别解决抽样检验、单阶段生产决策、多工序流程扩展以及抽样误差影响下的决策修正问题。
```

这句话明确了四类任务。

## 5. 问题重述的推荐结构

我现在给自己整理一个比较稳的结构。

```text
第一段：简要交代背景和核心矛盾。
第二段：整理题目给出的关键数据、条件和约束。
第三段：逐问重述，每一问都点出任务本质。
第四段：说明各问之间的递进关系，为后面问题分析铺垫。
```

这个结构不是固定模板，而是写作时的检查顺序。

### 5.1 第一段：背景和核心矛盾

这一段要短。

以 2024B 题为例：

```text
某企业的成品由多个零配件和半成品装配而成，各环节均可能产生次品。检测可以降低不合格品流入后续环节或市场的风险，但会增加检测成本；拆解可以回收部分零配件，却会产生拆解费用。因此，本题的核心是在质量风险和生产成本之间制定合理的检测、装配与拆解决策。
```

这个写法的好处是：一开始就把“检测有好处但有成本、拆解有收益但有费用”的矛盾讲出来。

### 5.2 第二段：关键条件

这一段可以用文字，也可以用简短列表。

例如：

```text
题目给出了两类生产场景：一类是由两种零配件组成的基础生产流程，另一类是包含多道工序、多个零配件和半成品的复杂流程。相关参数包括次品率、购买单价、检测成本、装配成本、市场售价、调换损失和拆解费用。企业需要根据这些参数决定是否检测零配件、是否检测成品以及是否拆解不合格品。
```

注意这里没有复制表格，而是把表格变量归类。

### 5.3 第三段：逐问重述

逐问重述最好一问一句或一问一小段。

可以这样写：

```text
问题一要求在给定信度要求下，为零配件批次设计尽可能少的抽样检测方案，并根据样本中检测出的次品数判断该批零配件应接收还是拒收。

问题二要求在已知零配件和成品次品率的基础上，对基础生产流程中的检测和拆解决策进行选择，并给出相应决策依据和指标结果。

问题三将生产结构扩展为多工序、多零配件和多半成品情形，要求在更复杂的装配关系下重复问题二的决策过程，形成完整生产方案。

问题四进一步考虑次品率由抽样检测得到而非真实已知，需要在抽样误差存在的条件下重新修正问题二和问题三的决策模型。
```

这段已经比原题更接近建模语言。

### 5.4 第四段：各问关系

这一段不是必须，但我觉得很有用。

例如：

```text
四个问题之间具有明显递进关系：问题一为次品率判断提供统计基础，问题二建立基础生产流程的决策模型，问题三将该决策模型推广到复杂多工序场景，问题四则把参数由确定值扩展为抽样估计值，考察不确定性对生产决策的影响。
```

这句话能让评阅老师看到我对整题结构的把握。

## 6. 用 2024B 题练习问题重述

### 6.1 从原题语言到建模语言

张胜利老师在 2024B 题讲评课中先讲问题背景、数据说明，再进入问题重述和解题要点。这个顺序对我很有启发。

原题给的是生产过程叙述，但建模时要看到背后的数学问题。

| 原题中的说法 | 我需要转化出的建模语言 |
|---|---|
| 标称次品率不超过10% | 次品率阈值、统计判决标准 |
| 95%信度拒收 | 拒收规则、第一类/第二类风险控制 |
| 尽可能少的抽样方案 | 最小样本量设计 |
| 是否检测零配件 | 0-1决策变量 |
| 是否拆解不合格品 | 返工/回收决策变量 |
| 调换损失和拆解费用 | 成本收益函数中的参数 |
| 多道工序和多个零配件 | 多阶段组合决策问题 |
| 次品率由抽样检测得到 | 参数估计误差、不确定性修正 |

我的理解：问题重述写得好不好，关键就看有没有完成这张表里的转换。

### 6.2 2024B 题问题重述示例

下面是一段可以放进论文里的问题重述草稿。它不是标准答案，而是按照课堂要求整理出来的写法。

```text
某企业生产的电子产品由零配件、半成品和成品逐级装配形成，各环节均可能存在次品。对零配件或成品进行检测可以减少不合格品进入后续流程或市场的风险，但会增加检测成本；对不合格品进行拆解可能回收部分零配件，但也会产生拆解费用。因此，本题需要在质量控制、生产成本、调换损失和拆解收益之间进行权衡，制定合理的检测与拆解决策。

题目给出了基础生产流程和多工序生产流程两类场景。基础场景中，成品由两种零配件装配而成，相关参数包括次品率、购买单价、检测成本、装配成本、市场售价、调换损失和拆解费用；扩展场景中，生产流程包含多种零配件、多个半成品和最终成品，决策维度明显增加。

问题一要求在给定信度水平下，为零配件批次设计尽可能少的抽样检测方案，并根据样本中检测出的次品数判断该批零配件应接收还是拒收。问题二要求在已知次品率条件下，对基础生产流程中的零配件检测、成品检测和不合格品拆解决策进行选择，并给出决策依据和指标结果。问题三将问题二推广到多工序、多零配件和多半成品生产流程，要求形成完整的生产过程决策方案。问题四进一步考虑次品率由抽样检测得到，真实次品率并不完全确定，因此需要分析抽样估计误差对问题二和问题三决策结果的影响，并对原决策模型进行修正。

四个问题之间具有递进关系：问题一提供次品率判断的统计基础，问题二建立基础生产流程的决策模型，问题三将模型推广到复杂生产结构，问题四则从确定参数转向抽样估计参数，考察不确定性对生产决策的影响。
```

### 6.3 这段示例的优点

这段重述比直接复制原题更好，原因是：

- 它先概括核心矛盾：检测成本、质量风险、调换损失、拆解费用之间的权衡。
- 它把表格参数归类，而不是把表格内容逐条搬进正文。
- 它逐问说明任务，而且每一问都点出建模方向。
- 它说明了四问之间的递进关系。
- 它没有提前写公式，也没有提前公布结果。

### 6.4 这段示例还能改进的地方

如果真正写比赛论文，还可以进一步结合本队模型修改：

- 如果问题一采用二项分布，就可以在问题重述中更明确写“统计检验问题”。
- 如果问题二采用期望利润最大化，就可以写“以收益指标为决策依据”。
- 如果问题三采用动态规划、穷举、粒子群或其他算法，可以在问题分析部分展开，问题重述这里只轻轻点到。
- 如果问题四使用贝叶斯修正或置信区间，可以在问题分析部分进一步说明。

我的提醒：问题重述要给后面留空间，不能把问题分析、模型假设、模型建立的内容全塞进来。

## 7. 问题重述和问题分析的衔接

卢楠老师课上讲问题重述时，提到要说明每一问拟采用的建模思路，简单对比备选方法优缺点。这里其实已经和下一章“问题分析”连起来了。

我现在的理解是：

```text
问题重述：这道题让我做什么。
问题分析：为什么可以这样建模。
```

问题重述不需要详细论证方法，但要让后文问题分析有入口。

例如：

- 问题重述中写“问题一是抽样检测方案设计”。
- 问题分析中再展开“为什么可用超几何分布、二项分布或正态近似”。

再如：

- 问题重述中写“问题二是检测与拆解的离散决策问题”。
- 问题分析中再展开“为什么每个决策可以设为0-1变量，目标函数应选成本还是利润”。

这样章节之间就不会断。

## 8. 我现在实际写问题重述的工作纸

前面讲了很多原则，但真正写的时候，我不能边写边想，很容易又回到“换句话抄题”。所以我现在给自己准备一张工作纸，先在草稿里填完，再写正文。

| 原题材料 | 我要保留什么 | 转成建模语言 | 后文落点 |
|---|---|---|---|
| 背景叙述 | 研究对象和核心矛盾 | 谁在什么约束下做什么决策/预测/评价 | 问题重述开头 |
| 表格数据 | 参数类型，不逐项照抄 | 质量参数、成本参数、收益参数、约束参数 | 数据准备、符号说明 |
| “是否”“选择”“安排” | 可控动作 | 0-1变量、整数变量、路径选择或方案选择 | 问题分析、模型建立 |
| “尽可能少”“最大”“最小” | 优化方向 | 目标函数或评价指标 | 问题分析 |
| “给出方案/判断/预测” | 输出要求 | 策略、判据、排序、预测值或区间 | 摘要、结果分析 |
| “由抽样得到”“存在误差” | 不确定性来源 | 参数估计、置信区间、误差传播 | 假设、评价与改进 |

这张表的好处是：它逼我把题目材料变成后文能用的东西。问题重述不是终点，而是给后面章节搭桥。

### 8.1 三层压缩法

我现在写问题重述时，尽量按三层压缩：

```text
题面原话 → 信息块 → 重述句
```

以 2024B 题为例：

| 层次 | 写法 |
|---|---|
| 题面原话 | 成品由零配件装配而成，零配件和成品可能有次品，企业可选择检测和拆解 |
| 信息块 | 生产对象、质量风险、检测成本、拆解收益、调换损失 |
| 重述句 | 本题需要在质量风险和生产成本之间权衡，制定检测、装配和拆解决策 |

这样写出来的句子既不是照抄题目，也不会脱离题目。

### 8.2 问题重述的“刹车线”

问题重述要点到为止，不能抢后面章节的内容。我给自己画三条刹车线：

| 不能越过的线 | 可以写到哪里 | 不要写什么 |
|---|---|---|
| 不抢问题分析 | 点出题型和任务本质 | 不详细比较算法优缺点 |
| 不抢模型建立 | 说清可控动作、目标和约束 | 不写完整变量表和目标函数 |
| 不抢结果分析 | 说明输出什么结果 | 不写最终数值和结论 |

比如可以写：

```text
问题二可重述为在给定质量和成本参数下选择检测与拆解决策的离散决策问题。
```

但不该在问题重述里写：

```text
设 x_i 为第 i 个零件是否检测，建立最大期望利润函数，求得最优策略为……
```

前一句给后面留入口，后一句已经越界。

## 9. 常见错误与修改方向

### 9.1 照抄原题

表现：保留大量题面原句，只是换了几个连接词。

修改方向：把原题里的叙述转成“对象、条件、任务、输出”。

```text
问题一要求在给定信度条件下，用尽可能少的样本判断零配件批次次品率是否超过标称水平，可重述为最小样本量下的抽样判决问题。
```

### 9.2 只列问题编号

表现：

```text
本文需要解决题目中的四个问题，并分别给出结果。
```

修改方向：写出每一问的建模身份。

```text
四个问题分别对应抽样判决、基础生产决策、多工序决策扩展和抽样误差下的模型修正。
```

### 9.3 条件没有归类

表现：把表格参数重新抄一遍，读者看不出这些数据怎么进入模型。

修改方向：按作用归类。

```text
题目参数可分为质量参数、成本参数、收益参数和返工损失参数，分别用于刻画产品合格风险、生产检测成本、市场收益和不合格品处理代价。
```

### 9.4 过早进入模型建立

表现：在问题重述里开始设变量、列函数、报结果。

修改方向：只写到“这是什么类型的问题”。

```text
该问的核心是对多个“是否执行”的操作进行选择，因此可先重述为离散决策问题，具体变量和目标函数在模型建立部分给出。
```

### 9.5 各问关系断开

表现：每问都写了，但像四道独立小题。

修改方向：补递进关系。

```text
整体上，四个问题由抽样判断到生产决策，由基础流程到复杂流程，再由确定参数扩展到抽样估计参数，难度逐步增加。
```

## 10. 我的自查清单

写完问题重述后，我不只查语言，还查它能不能支撑后文。

- 背景是否只保留研究对象和核心矛盾？
- 条件是否按数据、决策、约束、目标分类？
- 每一问是否都写出了任务本质？
- 有没有把“是否、选择、安排”转成决策语言？
- 有没有把“最大、最小、尽可能”转成目标语言？
- 有没有说明各问递进关系？
- 有没有提前写公式、变量表或最终结果？
- 后文的问题分析能不能自然接上？

## 11. 本章总结

这一章我主要学习了问题重述的写法，也把优化、图模型、拟合预测、动态过程、决策评价和机器学习这些专题课中的审题方式迁移了进来。

我现在对问题重述的理解是：

```text
问题重述 = 把题面语言压缩成后文能建模的任务语言
```

它不是简单换句话，也不是提前建模，而是完成一次转换：从原题的现实叙述，转成论文后面能继续分析的“对象、条件、任务、输出”。

从 2024B 题讲评中，我学到最重要的一点是：题目里的关键词都要往建模语言转化。比如“是否检测”意味着0-1决策；“尽可能少的抽样方案”意味着最小样本量；“次品率由抽样得到”意味着参数不确定性。下一次写问题重述前，我会先填“原题材料-建模语言-后文落点”这张表，再动笔写正文。
