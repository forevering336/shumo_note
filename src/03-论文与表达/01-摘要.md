# 第一章 摘要

## 0. 本章参考课程与写作原则

这一章主要依照数模集训里几节和论文、赛题讲评有关的课来整理：

- 卢楠老师的“建模论文写作及软件使用”课：主要参考摘要页要求、摘要结构、易扣分点、自查表。
- 刘磊老师的“论文写作”课：主要参考摘要应包含的内容、评卷标准、论文整体结构。
- 李金沙老师的“数模概论”课：主要参考“问题、模型、方法、结果必须交代清楚”和“写给评阅人看”的表达要求。
- 张胜利老师的“2024B题赛题讲评”课：主要参考 2024B 题四个问题的解题要点，用它来练习“摘要如何按问题写结果”。

本章不是单独讲“摘要是什么”，而是想回答一个更实际的问题：

> 国赛论文摘要到底应该怎么写，才能让评阅老师快速看到我的建模思路、求解方法和结果？

我这次重修笔记时给自己定的标准：

- 先写老师课堂上明确讲过的内容。
- 再写我从课堂内容中消化出来的理解。
- 如果是我自己的补充判断，会明确标成“我的理解”。
- 少堆通用模板，多联系 2024B 题讲评。

## 1. 摘要为什么重要

### 1.1 课堂中的原始要求

卢楠老师在论文写作课的摘要部分反复强调：摘要是评阅人对论文的第一印象，甚至会影响评阅人是否继续认真阅读正文。

刘磊老师在论文写作课中也提到，全国评阅时会先根据摘要和论文整体结构对论文优劣进行初步筛选。

李金沙老师在数模概论课中也强调，摘要的书写要说明：

- 要解决什么问题；
- 建立了什么模型；
- 用什么方法求解；
- 得到了什么结果；
- 得出什么结论。

这些课堂内容合起来说明：摘要不是最后随手写的一段概括，而是论文最先接受评阅的部分。

### 1.2 我的理解

我以前容易把摘要理解成“全文总结”，但现在感觉这个理解太浅了。数模论文的摘要更像是：

```text
一份压缩版答卷
```

它不是讲背景多重要，而是要让评阅老师迅速判断：

- 这个队伍有没有读懂题；
- 每一问有没有对应模型；
- 模型有没有数学表达；
- 结果是不是具体；
- 结果有没有检验；
- 论文有没有值得继续看的亮点。

所以摘要写不好，可能不是单纯的语言问题，而是说明整篇论文的逻辑链还没有压实。

## 2. 摘要的硬性格式要求

### 2.1 课堂中的格式要求

根据卢楠老师论文写作课中的要求：

- 摘要页是独立一页。
- 电子版论文第一页必须是摘要专用页。
- 摘要页包括标题、摘要正文、关键词。
- 摘要正文一般 600-800 字。
- 摘要中不出现图表、参考文献。
- 摘要页、正文、附录中不能出现队伍、学校、个人等身份信息。

刘磊老师在论文写作课中也提到：

- 论文题目和摘要写在第三页；
- 第四页开始是论文正文；
- 摘要在整篇论文评阅中占有重要权重。

### 2.2 我的整理

这一部分看起来像排版细节，但国赛里不能轻视。

我需要特别记住：

- 摘要必须独立成页。
- 摘里不要放图表。
- 摘要里不要写参考文献。
- 不要出现学校、姓名、队伍等身份信息。
- 关键词不要漏。
- 摘要里的模型名和正文必须一致。

## 3. 摘要应该包含什么

### 3.1 卢楠老师课中的摘要结构

卢楠老师给出的摘要核心结构是：

```text
问题概述
→ 数据预处理
→ 各问模型 + 方法
→ 量化结果
→ 模型检验 + 优缺点 + 价值
→ 关键词
```

其中老师特别强调：

- 各问模型 + 方法是核心。
- 量化结果必须带数字。
- 不能只说“结果较好”。
- 关键词要写核心模型和研究对象。

### 3.2 刘磊老师课中的摘要要点

刘磊老师对摘要内容的要求可以整理为：

- 用 1-2 句话说明原题要求解决的问题。
- 写清建立什么模型，数学上属于什么类型。
- 写清建模思想、模型特点。
- 写清算法思想，也就是求解思路。
- 写主要结果，包括数值结果和结论。
- 写模型优点、模型检验、灵敏度分析、改进和推广。

这和卢楠老师课中的结构是对应的，只是刘磊老师这里更强调“数学上属于什么类型”和“算法思想”。

### 3.3 李金沙老师课中的提醒

李金沙老师对摘要的提醒比较直接：

- 摘要要强调说明方法；
- 按问题给出结果；
- 特别是综合的结果；
- 模型、方法、结果必须交代清楚；
- 必要时突出创新之处。

这里我觉得最重要的是“按问题给出结果”。因为国赛题一般分成多个小问，如果摘要只写“本文建立模型求解了问题”，就没有真正回答题目。

## 4. 我对摘要的基本判断

### 4.1 摘要不是背景介绍

课上提到一个常见问题：大段写背景意义，没有模型，没有关键量化结果，通篇空话。

所以摘要开头不能写成这样：

> 随着社会经济的发展，生产决策问题越来越重要。本文针对生产过程进行了研究，并建立了相关模型，最后得到了较好的结果。

这类话的问题是：

- 没有说明具体研究对象；
- 没有说明题目有几个问题；
- 没有模型名称；
- 没有算法；
- 没有数字结果；
- 评阅老师看不到论文贡献。

更接近课堂要求的写法应该是：

> 针对多工序生产过程中零配件检测、成品检测与不合格品拆解之间的成本收益权衡问题，本文围绕抽样检测方案、单阶段生产决策、多工序生产决策和抽样误差下的模型修正展开研究。

这个开头没有华丽语言，但能让人马上知道题目对象和四个小问。

### 4.2 摘要要围绕“模型、算法、结果”

刘磊老师把评卷标准概括为：假设的合理性、模型的创新性、结果的正确性、文字清晰程度。

所以摘要要服务这四点：

- 写问题和假设边界，让人知道假设是否合理；
- 写模型类型，让人看到建模水平；
- 写算法和结果，让人判断结果是否可信；
- 写得清楚，让人愿意继续读正文。

我现在总结一个最简单的摘要检查句：

```text
没有模型名，不算摘要完整；
没有算法或求解思路，不算摘要完整；
没有具体结果，不算摘要完整；
没有按小问回应，不算摘要完整。
```

## 5. 摘要各部分怎么写

### 5.1 标题

卢楠老师提到，标题一般控制在 18-32 字，超过 40 字会显得臃肿；标题要点明核心，不能夸大。

老师提醒：

- 没做神经网络，不要写“基于神经网络”；
- 没改进算法，不要写“新型 XX 算法”；
- 标题要让人一眼看出研究什么问题、用了什么核心思路。

我的理解：标题不是为了显得高级，而是为了准确。

例如 2024B 题如果写：

```text
基于智能算法的复杂系统优化研究
```

就太虚了，看不出是生产过程，也看不出是检测和拆解决策。

更稳一点可以写：

```text
基于抽样检验与0-1规划的生产过程决策模型
```

这个标题至少点出了抽样检验、0-1 规划和生产过程决策。

### 5.2 问题概述

课堂要求：用 1-2 句话概括题目背景，说明需要解决哪几个问题。

我理解这里最重要的是“概括”，不是照抄题目。李金沙老师在问题重述部分提醒，不能照搬原文，要把原问题用数学语言表达出来。

摘要中的问题概述可以按这个顺序写：

```text
研究对象
→ 主要矛盾
→ 小问任务
```

以 2024B 题为例：

```text
针对生产过程中零配件、半成品和成品质量检测带来的成本收益权衡问题，本文研究抽样检测方案设计、给定次品率下的生产决策、多工序生产决策扩展以及抽样误差影响下的模型修正。
```

这句话不是答案，但它让摘要有了方向。

### 5.3 数据预处理

卢楠老师提到，摘要中可以用 1-2 句话说明数据预处理，比如缺失值、异常值、3σ 准则、均值填充、箱线图剔除等。

我的理解是：不是所有题都要在摘要里写数据预处理。只有当数据处理影响模型可靠性时，才值得写。

例如：

- 预测题：要说明异常值、缺失值怎么处理。
- 评价题：要说明指标正负向、标准化方法。
- 抽样题：要说明样本比例、置信区间、参数估计。
- 优化题：如果数据直接来自题目表格，摘要里可以少写数据处理，把篇幅留给模型和结果。

以 2024B 题为例，问题四涉及“次品率由抽样检测得到”，这时就应该提到参数估计误差。

可以写：

```text
考虑题中次品率由抽样检测得到，本文用抽样分布或贝叶斯置信区间刻画真实次品率的不确定性，并将修正后的次品率作为后续决策模型的输入。
```

这里是根据张胜利老师讲 2024B 题时的问题四要点整理的。

### 5.4 各问模型和方法

这是摘要最核心的部分。

课堂要求摘要要写：

- 每一问用了什么模型；
- 为什么选这个模型；
- 有没有做改进；
- 用什么算法求解；
- 不要只写软件名。

我的理解是：摘要中不能把模型写成“我做了问题一、问题二、问题三”，而要写成“每个问题被我转化成了什么数学问题”。

#### 问题一：抽样检测

张胜利老师讲 2024B 题时，问题一的要点是：

- 设计尽可能少的抽样检测方案；
- 这是数理统计抽样问题；
- 通过抽样数和检测次品数判断实际批次次品率；
- 批量小时可考虑超几何分布，批量大时可用二项分布近似，抽样数大时可用正态近似；
- 结果可以用图像或表格说明。

摘要中可以写：

```text
针对问题一，本文将最小抽样方案设计转化为统计判决问题，根据批量大小选择超几何分布或二项分布近似，以样本量最小和信度约束满足为目标，确定最大允许次品数下的接受判据。
```

我的理解：这句话的重点不是“用了统计方法”，而是把“样本量”“次品数”“信度”“接受判据”这些评分点写出来。

#### 问题二：给定次品率下的生产决策

张胜利老师讲 2024B 题时，问题二的要点是：

- 要根据表格信息制定生产决策方案；
- 重点考虑决策依据，比如期望成本、收益或利润；
- 要根据决策依据建立具体决策模型；
- 要确定详细的决策指标；
- 如果拆解成本很高，应考虑占优策略简化；
- 已检测过的拆下零件不需要重复检测；
- 未检测零件被拆下后，需要重新计算其为次品的条件概率。

摘要中可以写：

```text
针对问题二，本文以期望利润最大为决策依据，设置零配件检测、成品检测和不合格品拆解等0-1决策变量，建立生产过程整数规划模型，并结合检测记录和条件概率修正拆解后零配件的可用性判断。
```

我的理解：这一问不能只写“建立决策模型”。因为讲评课明确指出，要说清决策依据和指标。摘要里至少要出现“期望成本/收益/利润”中的一个。

#### 问题三：多工序生产决策

张胜利老师讲 2024B 题时，问题三的要点是：

- 流程更复杂；
- 要考虑是否可以简化过程，并说明简化合理性；
- 应给出每个过程具体的决策方案；
- 包括评价指标和决策依据。

张胜利老师后面的解题思路中还提到，当问题三比问题二复杂时，可以引入粒子群算法；并且可与穷举法进行对比。

摘要中可以写：

```text
针对问题三，本文在问题二模型基础上扩展到多工序、多零配件情形，将各阶段检测与拆解决策编码为0-1向量，采用粒子群算法搜索高维组合决策空间，并在可穷举的小规模情形下对算法结果进行验证。
```

我的理解：这一问的摘要要体现“递进”：不是重新写一个模型，而是从问题二推广到更复杂流程。李金沙老师也提醒模型之间要有递进性，可以由简到难，先给简单模型，再改进得到下一个模型。

#### 问题四：抽样误差下的模型改进

张胜利老师讲 2024B 题时，问题四的要点是：

- 次品率由抽样检测获得，真实次品率不可知；
- 应类比问题一模型，对问题二、三提出改进方案；
- 抽样方案可以作为决策的一部分；
- 模型中应考虑批量大小；
- 要明确求解方法、决策依据和指标；
- 要分析抽样估计误差对决策的影响；
- 可以考虑不同过程之间次品率相互影响。

摘要中可以写：

```text
针对问题四，本文考虑次品率由抽样检测估计而非真实已知，引入二项分布或贝叶斯置信区间修正次品率参数，并将参数不确定性传递到问题二、三的生产决策模型中，分析抽样误差对最优策略和期望利润的影响。
```

我的理解：问题四是很能体现建模水平的一问。它不是简单“重做问题二三”，而是把确定性参数变成不确定参数，再看决策是否变化。

### 5.5 量化结果

卢楠老师明确强调：摘要必须带具体数字。课件举的量化结果包括：最优总成本、R²、权重、排名贴近度、误差指标。

课件还说，不能只写“结果较好”。

刘磊老师也要求摘要写主要结果，包括数值结果和结论。

我的理解：摘要里的结果必须能被正文表格或计算过程支撑。可以没有很多数字，但至少要放最关键的 1-2 个数字或判据。

2024B 题中比较适合放进摘要的结果包括：

- 问题一的最小样本量；
- 最大允许次品数；
- 接受或拒绝批次的判据；
- 问题二不同情形下的最优检测/拆解策略；
- 对应的期望利润或成本；
- 问题三多工序下的最优策略；
- 问题四修正次品率后策略是否变化；
- 参数扰动后利润或策略变化幅度。

可以写成：

```text
计算结果表明，在95%信度要求下，当样本量为 n、最大允许次品数为 c 时可接受该批零配件；在表1给定参数下，最优策略为……，对应期望利润为……元。
```

这里的 `n`、`c`、利润必须在正式论文中换成真实计算值。

我的提醒：如果结果还没算完，不要先在摘要里编数字。宁可留到最后填，也不能让摘要和正文不一致。

### 5.6 模型检验、灵敏度分析和稳健性

卢楠老师在课中多次强调：

- 摘要应简要说明模型检验、灵敏度、稳健性结论；
- 只做结果展示，没有灵敏度、稳健性、误差分析，是常见扣分点；
- 可以通过更换模型、指标、权重等方式完成稳健性检验。

李金沙老师也提到，要进行模型灵敏度分析、结果检验、模型改进和优缺点分析。

结合 2024B 题，我可以这样理解：

- 问题一：改变真实次品率或样本量，看接受判据是否合理；
- 问题二：改变检测成本、拆解成本、调换损失，看最优策略是否变化；
- 问题三：用小规模穷举验证粒子群算法结果；
- 问题四：看抽样误差修正后，策略和利润变化有多大。

摘要中可以写：

```text
通过改变检测成本、拆解费用和次品率参数进行灵敏度分析，结果显示关键参数在给定范围内扰动时主要策略保持稳定；同时在小规模情形下用穷举结果验证粒子群算法的可靠性。
```

注意：这句话只有在正文真的做了这些分析时才能写。

### 5.7 关键词

卢楠老师要求关键词 3-5 个，写核心模型和研究对象。

如果是 2024B 题，我认为关键词可以是：

```text
抽样检验；0-1整数规划；生产决策；粒子群算法；灵敏度分析
```

或者：

```text
二项分布；质量检测；整数规划；组合优化；贝叶斯修正
```

关键词不要写得太泛，比如：

```text
数学建模；数据分析；优化；决策
```

这种关键词看起来什么都包括，但不能体现论文特点。

## 6. 摘要和 2024B 题讲评的对应关系

这一节是我本章最重要的训练：用试题讲评反推摘要怎么写。

### 6.1 讲评课告诉我什么

张胜利老师这节 2024B 题讲评课的结构是：

```text
问题背景
→ 问题重述
→ 解题要点
→ 解题思路
→ 评阅综述
```

我现在理解，写摘要时最应该抓的是“解题要点”和“解题思路”，因为这两部分对应评分点。

2024B 四问可以压缩成下面这张表。

| 小问 | 讲评中的问题本质 | 摘要中要写出的关键词 |
|---|---|---|
| 问题一 | 抽样检测和统计判决 | 样本量、次品数、信度、二项分布/超几何分布 |
| 问题二 | 已知参数下的生产决策 | 期望成本/收益/利润、0-1变量、检测、拆解 |
| 问题三 | 多工序复杂决策扩展 | 多阶段、多零配件、组合优化、过程简化、粒子群 |
| 问题四 | 抽样误差下的模型改进 | 真实次品率未知、置信区间、贝叶斯修正、误差影响 |

### 6.2 用 2024B 题写一段摘要雏形

下面这段不是正式答案，而是根据讲评课件整理出的摘要雏形。正式论文中必须补真实数字。

```text
针对多工序生产过程中质量检测、成品退换和不合格品拆解之间的成本收益权衡问题，本文围绕抽样检测方案、给定次品率下的生产决策、多工序决策扩展以及抽样误差下的模型修正展开研究。

针对问题一，将最小抽样方案设计转化为统计判决问题，根据批量大小选择超几何分布或二项分布近似，以样本量最小和信度要求满足为目标，确定最大允许次品数下的接受判据。

针对问题二，以期望利润最大为决策依据，设置零配件检测、成品检测和不合格品拆解等0-1变量，建立整数规划模型，计算不同策略下的期望收益并确定各情形最优方案。

针对问题三，在问题二基础上扩展到多工序、多零配件生产流程，将各阶段检测与拆解决策统一编码为0-1向量，采用粒子群算法搜索高维组合决策空间，并用小规模穷举结果进行验证。

针对问题四，考虑次品率由抽样检测估计而非真实已知，引入二项分布或贝叶斯置信区间修正次品率参数，重新求解问题二、三的生产决策模型，并分析抽样估计误差对最优策略和期望利润的影响。
```

这段还不是好摘要，因为缺少具体结果数字。它只是模型和方法骨架。

正式摘要还要补：

- 问题一的最小样本量和最大允许次品数；
- 问题二的最优策略和期望利润；
- 问题三的最优策略、算法结果；
- 问题四修正前后策略或利润变化；
- 灵敏度或稳健性结论。

### 6.3 我从 2024B 题学到的摘要写法

这道题让我意识到，摘要不是平均写四问，而是要写清每一问的“建模身份”。

我的理解：

- 问题一不是“算一个抽样方案”，而是“统计判决模型”。
- 问题二不是“做生产决策”，而是“0-1 决策优化”。
- 问题三不是“问题二变复杂”，而是“高维组合优化”。
- 问题四不是“重新求解”，而是“参数不确定性下的模型修正”。

如果摘要能把这四层意思写出来，评阅老师会更容易看出论文的层次。

## 7. 常见扣分点与我的修改方向

这一节主要依照卢楠老师课上的易扣分点整理。

### 7.1 扣分点一：大段背景，没有模型和结果

表现：

```text
随着社会发展，某问题越来越重要……
```

修改方向：

```text
针对【对象】中的【矛盾】，本文研究【几个具体问题】。
```

我自己的提醒：摘要开头最多 1-2 句话交代背景，后面马上进入模型。

### 7.2 扣分点二：只写做了什么，不写具体数字

表现：

```text
本文建立模型并进行了求解，结果较好。
```

修改方向：

```text
模型得到最优总成本为……万元，预测误差为……，贴近度为……。
```

我自己的提醒：“较好、合理、有效”这几个词要少用，除非后面有数字支撑。

### 7.3 扣分点三：缺少模型检验和灵敏度分析

表现：

```text
摘要只给最优方案，没有说明结果是否稳定。
```

修改方向：

```text
通过关键参数扰动和对比实验验证结果稳定性。
```

结合 2024B：

- 可以扰动检测成本；
- 可以扰动拆解成本；
- 可以扰动次品率；
- 可以比较穷举和粒子群结果；
- 可以比较修正次品率前后的策略。

### 7.4 扣分点四：标题或摘要夸大模型

表现：

```text
没做神经网络，却写“基于深度学习”。
普通枚举，却写“智能优化算法”。
```

修改方向：模型名称必须和正文一致。

我自己的提醒：宁可朴素准确，不要虚高。数模论文不是广告词。

### 7.5 扣分点五：摘要和正文不一致

表现：

- 摘要里写了模型检验，正文没有；
- 摘要写的最优方案和正文表格不同；
- 摘要中的数字和正文不一致；
- 摘要中的关键词和正文核心模型不一致。

修改方向：摘要最后定稿，每个数字都回正文核对。

## 8. 我现在形成的摘要写作流程

这部分是我的补充理解，不是老师原话。

### 8.1 第一步：从题目拆小问

先把每一问写成一句“问题类型判断”。

例如 2024B：

```text
问题一：抽样检测与统计判决。
问题二：已知参数下的0-1生产决策。
问题三：多工序组合优化。
问题四：参数估计误差下的模型修正。
```

如果这一步写不出来，摘要肯定写不好。

### 8.2 第二步：给每一问配模型

按课堂要求，要写清“建立什么模型，在数学上属于什么类型”。

例如：

```text
问题一：二项分布/超几何分布抽样检验模型。
问题二：0-1整数规划模型。
问题三：高维组合优化模型，粒子群算法求解。
问题四：贝叶斯置信区间或抽样误差修正模型。
```

### 8.3 第三步：给每一问配结果

每一问至少要有一个可以落地的结果。

例如：

```text
问题一：最小样本量 n，最大允许次品数 c。
问题二：每种情形下是否检测、是否拆解，期望利润。
问题三：多工序最优策略，算法结果。
问题四：修正后策略变化，利润变化，误差影响。
```

### 8.4 第四步：补检验和优缺点

摘要最后要有一点检验意识。

可以写：

```text
通过关键参数扰动分析和算法对比验证，模型结果在一定范围内保持稳定。
```

但前提是正文真的做了。

## 9. 我的摘要检查清单

写完摘要后，我要按下面清单检查。

### 9.1 内容检查

- 有没有用 1-2 句话说明题目要解决什么？
- 有没有按问题一、问题二、问题三、问题四分别写？
- 有没有写清楚每一问的模型类型？
- 有没有写清楚求解方法，而不是只写软件名？
- 有没有具体数字或明确判据？
- 有没有模型检验、灵敏度分析或稳健性说明？
- 有没有写模型优点、不足或应用价值？
- 有没有关键词？

### 9.2 结果检查

- 摘要中的每个数字能不能在正文找到？
- 摘要中的单位是否完整？
- 摘要中的最优方案是否和正文一致？
- 摘要中的检验结论是否有图表或计算支撑？
- 摘要是否回答了题目所有小问？

### 9.3 表达检查

- 有没有照搬原题？
- 有没有大段背景空话？
- 有没有使用没有依据的高级词？
- 有没有写“结果较好”但不给证据？
- 有没有出现身份信息？
- 有没有图表、参考文献或不必要缩写？

## 10. 本章总结

这一章我主要从论文写作课和 2024B 题讲评课中整理摘要写法。

我现在对摘要的理解是：

```text
摘要 = 问题 + 模型 + 方法 + 结果 + 检验 的压缩版
```

其中最关键的是：

- 要按问题写，不要泛泛概括；
- 要写模型类型，不要只说“建立模型”；
- 要写求解思路，不要只写 MATLAB 或 Python；
- 要写量化结果，不要只说“较好”；
- 要写检验和稳健性，不要只展示结果；
- 要和正文完全一致。

从 2024B 题我学到的最重要一点是：摘要要能体现每一问的建模层次。问题一是抽样统计，问题二是0-1决策，问题三是组合优化扩展，问题四是不确定性修正。把这些层次写出来，摘要才像真正读懂了题。

下一次我自己写训练题摘要时，应该先做一张“小问-模型-算法-结果-检验”表，再把表压缩成摘要正文。这样写出来的摘要会更贴近论文讲解课里的要求，也更不容易变成空话。
