# 第七章 模型的评价与改进

## 0. 本章承接与学习重点

模型求解之后，论文不能只停在“结果如表所示”。真正能拉开差距的是：结果是否可信，模型是否稳定，误差来自哪里，模型还有什么改进空间。

这一章需要综合很多专题课：

- 卢楠老师和刘磊老师的论文写作课提醒我，必须有结果分析、模型检验、灵敏度分析、稳健性检验和模型优缺点。
- 杨雨茜老师的插值与拟合课提醒我，拟合模型要看残差、均方误差、最大误差，不能只看曲线好不好看。
- 董灏老师的微分方程数值方法课提醒我，数值解要关注步长、收敛性、稳定性和误差。
- 张朝辉老师的智能优化课提醒我，智能算法要看收敛曲线、参数设置、多次运行稳定性，不能只报一次最优值。
- 陈华老师的机器学习课提醒我，数据驱动模型要看泛化能力，训练集表现好不等于预测可靠。
- 唐厚俭老师的建模假设课提醒我，工程模型不追求绝对精确，但要稳定、容错、好用。

所以模型评价的核心不是“夸模型”，而是：

```text
说明结果为什么可信，模型哪里可靠，哪里还有限制。
```

## 1. 结果分析：先解释结果

### 1.1 结果不能只罗列

错误写法：

```text
运行程序得到结果如下。
```

这只是展示，不是分析。

更好的写法：

```text
由表可见，策略 A 的期望利润最高，为 XX 元/件，比次优策略高出 XX 元/件。该策略选择检测成品但不拆解不合格品，说明在当前拆解费用较高时，拆解收益不足以抵消拆解成本。
```

这才把数学结果翻译成现实解释。

### 1.2 不同模型的结果分析重点不同

| 模型类型 | 结果分析重点 |
|---|---|
| 优化模型 | 最优值、最优方案、约束是否满足、次优方案差距 |
| 决策模型 | 决策依据、策略变化原因、风险收益权衡 |
| 拟合模型 | 拟合优度、残差分布、误差大小、趋势解释 |
| 图模型 | 路径/网络结构是否合理，关键节点或边是什么 |
| 微分方程模型 | 变化趋势、平衡点、数值解是否稳定 |
| 机器学习模型 | 训练/测试误差、泛化能力、特征重要性 |
| 智能优化模型 | 收敛过程、最优值波动、算法是否稳定 |

这张表提醒我：不能所有结果都只写“模型有效”。

## 2. 模型检验

### 2.1 检验的基本思路

模型检验可以从几类入手：

- 约束检验：结果是否满足题目约束；
- 常识检验：极端情况是否符合现实直觉；
- 对比检验：和其他方法或小规模精确解比较；
- 误差检验：预测值和真实值差距多大；
- 稳定性检验：参数或初值变化时结果是否稳定。

### 2.2 2024B 题中的检验

- 问题一：信度提高时，样本量一般应增大；真实次品率越接近标称值，判别越困难。
- 问题二：最优策略必须满足检测、装配、拆解流程；成本收益不能漏项。
- 问题三：粒子群结果可用小规模穷举验证；多次运行最优利润不应大幅波动。
- 问题四：修正后的次品率应落在合理区间；策略变化应能由抽样误差解释。

## 3. 误差分析：不同模型看不同误差

### 3.1 插值与拟合误差

杨雨茜老师讲插值拟合时，误差意识很重要。

拟合模型常看：

- 残差 $r_i=S(x_i)-y_i$；
- 残差平方和；
- 均方误差；
- 最大误差；
- 拟合优度。

插值模型要警惕：

- 高次插值的龙格现象；
- 端点振荡；
- 外推风险；
- 节点误差被放大。

如果论文用了数据拟合，不能只贴拟合曲线，至少要说明误差指标。

### 3.2 数值方法误差

董灏老师的数值方法课提醒我，微分方程或数值计算模型要注意：

- 步长大小；
- 截断误差；
- 舍入误差；
- 收敛性；
- 稳定性。

如果使用数值方法，可以通过改变步长进行检验：

```text
将步长减半后重新计算，若主要结果变化较小，说明数值解具有一定稳定性。
```

### 3.3 智能优化误差

智能优化算法常带随机性。

评价时要看：

- 收敛曲线；
- 多次运行最优值分布；
- 参数设置是否合理；
- 是否陷入局部最优；
- 是否与小规模精确算法对比。

问题三如果用粒子群，只跑一次就报最优值是不够的。

### 3.4 机器学习误差

陈华老师的机器学习课提醒我，模型泛化能力很关键。

如果使用机器学习，要看：

- 训练误差和测试误差；
- 是否过拟合；
- 数据分布是否覆盖预测场景；
- 标签误差；
- 特征是否合理。

张朝辉老师也讲到神经网络会“记住训练数据噪声”，需要正则化、数据增强等手段控制过拟合。

## 4. 灵敏度分析

### 4.1 选核心参数

灵敏度分析不是随便改参数，而是改对结果有重要影响的参数。

不同模型中可选：

- 优化模型：成本、收益、容量、权重；
- 决策模型：概率、损失、风险偏好；
- 拟合模型：异常点、拟合阶数；
- 数值模型：步长、初值、关键参数；
- 智能优化：种群规模、迭代次数、学习因子；
- 机器学习：训练集比例、特征选择、模型超参数。

### 4.2 2024B 题中的灵敏度

适合扰动：

- 检测成本；
- 拆解费用；
- 调换损失；
- 次品率；
- 样本量；
- 信度水平。

结论要写清：

```text
哪个参数最敏感？
策略是否变化？
利润变化幅度多大？
临界点在哪里？
```

## 5. 稳健性检验

### 5.1 稳健性和灵敏度不同

我的理解：

```text
灵敏度：参数变了，结果怎么变。
稳健性：方法或设置换了，结论还成立吗。
```

### 5.2 可以怎样检验

- 换模型：TOPSIS 换灰色关联，看排序是否接近。
- 换算法：粒子群换遗传算法，看最优值是否接近。
- 换权重：熵权换组合权重，看评价结果是否稳定。
- 换步长：微分方程数值解改变步长，看曲线是否稳定。
- 换样本：训练集/测试集划分变化，看预测误差是否稳定。

稳健性检验体现的是：我的结论不是某一次设置碰巧得到的。

## 6. 模型优缺点和改进

### 6.1 优点要具体

不要写：

```text
模型合理，效果较好。
```

可以写：

```text
模型将检测成本、拆解费用和调换损失统一到期望利润框架中，能够直接比较不同策略的经济效果，且0-1变量使决策结果具有较强可解释性。
```

### 6.2 不足要真实

可以从这些角度写：

- 假设过于理想；
- 数据量不足；
- 参数固定；
- 算法随机性；
- 未考虑动态变化；
- 模型泛化范围有限；
- 误差来源没有完全消除。

### 6.3 改进要对应不足

| 不足 | 改进 |
|---|---|
| 检测假设无误判 | 引入误检率、漏检率 |
| 成本固定 | 建立区间成本或随机成本模型 |
| 粒子群有随机性 | 多算法融合或多次运行取稳健解 |
| 数据含噪声 | 鲁棒拟合或异常值处理 |
| 训练数据有限 | 扩充数据集或迁移学习 |
| 动态变化未考虑 | 建立动态规划或时序模型 |

唐厚俭老师讲工程建模时的思想很适合写改进：不追求绝对精确，但要更稳定、更容错、更适合实际。

### 6.4 改进不是另起炉灶

模型改进最容易写偏。有些论文一到改进部分，就突然提出一个正文完全没用过的新模型，这样反而像补丁。更自然的改进应该从当前模型的不足长出来。

我现在给自己列一个“诊断到改进”的链条：

| 诊断发现 | 说明模型哪里弱 | 更自然的改进方向 |
|---|---|---|
| 结果对某个成本参数特别敏感 | 参数固定假设太强 | 做区间参数、随机参数或稳健优化 |
| 粒子群多次运行结果波动较大 | 随机搜索稳定性不足 | 增加多次运行统计、混合局部搜索或与枚举小规模对照 |
| 拟合残差在某一区间系统偏正/偏负 | 函数形式不合适 | 换分段拟合、非线性拟合或加入关键变量 |
| 数值解随步长变化明显 | 数值稳定性不足 | 缩小步长、换更稳定算法、做误差阶检验 |
| 训练集效果好但测试集差 | 过拟合或样本代表性不足 | 正则化、特征筛选、交叉验证、扩充样本 |
| 某些约束在现实中被忽略 | 模型简化过度 | 补充工艺约束、容量约束、时间约束或风险约束 |

这张表的作用是防止我写空话。改进必须能回答：我发现了什么问题，所以我准备怎样修。

### 6.5 2024B 题里可以怎样写评价和改进

如果拿 2024B 题练习，评价与改进可以这样落地：

- 问题一：检查不同真实次品率下接收/拒收概率是否符合信度要求；改进方向是考虑有限批量下超几何分布与二项近似的差异。
- 问题二：检查最优策略是否对检测成本、拆解费用、调换损失敏感；改进方向是把固定成本改成区间成本。
- 问题三：如果用粒子群，检查多次运行最优值是否稳定；改进方向是用小规模穷举验证编码正确性，或加入局部搜索。
- 问题四：检查抽样估计次品率变化后策略是否发生跳变；改进方向是引入贝叶斯更新或稳健决策，避免策略对单次抽样过度敏感。

我的理解：这比泛泛写“模型有一定局限性，以后可进一步改进”更像真的做过题。
## 7. 本章自查清单

- 是否解释了结果，而不是只罗列？
- 是否做了模型检验？
- 拟合模型是否有残差或误差指标？
- 数值模型是否说明步长和稳定性？
- 智能优化是否有收敛和多次运行分析？
- 机器学习是否有泛化和过拟合讨论？
- 是否做了核心参数灵敏度分析？
- 是否做了稳健性检验？
- 优点是否具体？
- 不足是否真实？
- 改进是否对应不足？

## 8. 本章总结

模型评价与改进要吸收各类模型的评价标准。

我现在的理解是：

```text
评价模型 = 看结果、看误差、看稳定、看适用范围
```

这一章不能只写“模型优点和缺点”，而要根据具体方法评价：拟合看残差，数值法看稳定性，智能优化看收敛，机器学习看泛化，决策模型看风险收益，优化模型看约束和目标。这样评价才有内容。
