# 第三章 问题分析

## 0. 本章承接与学习重点

前两章解决的是“论文开头怎么写”：摘要展示成果，问题重述把原题转成自己的理解。第三章开始真正进入建模思维：面对一道题，我怎样判断它属于什么问题，应该往哪个模型方向走。

这一章不能只依照论文写作课。真正有帮助的是很多专题课共同提供的“判断视角”：

- 卢楠老师和刘磊老师的论文写作课提醒我，问题分析不能只是重复题目，要说明每一问的建模思路和方法选择理由。
- 穆学文老师的最优化模型课提醒我，优化问题至少要抓住“可行方案”和“目标”，进一步落到决策变量、约束和目标函数。
- 龚育冬老师的图上优化课提醒我，离散问题不一定只用整数规划；当对象之间存在关系、路径、连接、转移时，可以从“对象—关系—约束”出发转成图结构。
- 杨雨茜老师的插值与拟合课提醒我，数据类问题要先判断数据是“精确点”还是“带噪声观测”，这会直接决定用插值还是拟合。
- 邹青松老师的决策模型课提醒我，决策问题要区分确定、不确定和风险情形，不能把所有选择题都写成简单优化。
- 张朝辉老师的智能优化与强化学习课提醒我，算法选型要看问题类型：连续优化、组合优化、序贯决策、多目标、多智能体，对应的算法思路不同。
- 张胜利老师的 2024B 题讲评课则提供了具体样例：一个赛题中的四问可能分别对应统计检验、离散决策、组合优化和参数不确定性。

所以本章的核心不是背模型，而是训练一种能力：

```text
看到题目要求 → 判断问题类型 → 找到核心矛盾 → 选择合适模型方向
```

## 1. 问题分析到底分析什么

### 1.1 不只是把后面模型提前说一遍

张朝辉老师在论文写作部分特别提醒，很多人觉得问题分析就是把后面要建立的模型直接说一遍，但其实不是。问题分析应该写的是刚拿到题时的切入点：使用哪些信息，大概用什么方法，主要矛盾是什么。

我的理解是：

```text
问题分析 = 从题目语言到模型方向的桥
```

它还不是完整建模，但要让后面的模型出现得自然。

### 1.2 问题分析要回答的几个问题

每一问至少要想清楚：

- 这一问让我们输出什么？数值、方案、排序、预测、证明，还是策略？
- 已知条件是什么？数据、约束、流程、概率、成本、结构？
- 决策量或未知量是什么？
- 评价标准是什么？成本、利润、误差、风险、效率、稳定性？
- 难点在哪里？数据噪声、变量太多、约束复杂、无法解析求解、不确定性？
- 可以选择哪些方法？为什么选当前方法？

## 2. 从优化课学到的问题分析方法

### 2.1 优化问题先找两个基本要素

穆学文老师讲最优化模型时说，最优化模型至少有两个要素：一是可能的方案，二是要追求的目标。更完整地建立优化模型，还要有决策变量和参数、约束或限制条件、目标函数。

这给了我一个非常实用的审题方法：

```text
如果题目要“最优”“最大”“最小”“尽可能”“合理安排”，先问：
1. 可行方案是什么？
2. 目标是什么？
3. 约束是什么？
```

例如 2024B 问题二：

- 可行方案：是否检测零配件、是否检测成品、是否拆解不合格品的组合。
- 目标：可以是期望利润最大，也可以是期望成本最小。
- 约束：检测流程、装配流程、调换规则、拆解规则。

这样一分析，问题二就不是“生产流程描述”，而是一个离散决策优化问题。

### 2.2 优化问题要区分连续和离散

连续变量适合连续优化方法，离散变量适合整数规划、枚举、动态规划、图模型、启发式算法等。

2024B 中“是否检测”“是否拆解”天然是 0-1 变量，所以不能把它写成普通连续变量。问题三变量数量增加后，简单穷举会有组合爆炸，这时就要考虑智能优化或结构化简化。

我的提醒：问题分析阶段就要说明变量类型。因为变量类型决定求解方法。

## 3. 从图上优化课学到的问题分析方法

### 3.1 什么时候想到图模型

龚育冬老师的图上优化课有一条主线：图结构让离散问题可表达、可计算、可展示。面对离散决策问题，要从“对象—关系—约束”出发，判断能不能转成图结构。

我现在看到以下特征会想到图模型：

- 有节点和连接关系；
- 有路径、路线、流量、转移；
- 有网络结构；
- 有阶段状态之间的转移；
- 有多个对象之间的依赖；
- 需要可视化流程或关系。

例如：

- 路径规划：城市/路口是节点，道路是边。
- 供应链：供应商、仓库、客户是节点，运输关系是边。
- 生产流程：零配件、半成品、成品之间存在装配关系，可以用树或有向图表达。
- 任务调度：任务是节点，先后约束是边。

### 3.2 图模型对论文表达的帮助

图模型不仅是求解工具，也是表达工具。

在论文中，如果题目流程复杂，可以先画图：

```text
对象是什么 → 关系是什么 → 边权表示什么 → 约束是什么
```

比如 2024B 问题三，多工序、多零配件、多半成品的结构比较复杂。如果只用文字写，会很绕；如果用有向图或树状图表达装配关系，后面定义变量和递推计算都会更清楚。

我的理解：图结构有时不是为了显得高级，而是为了让复杂关系变得可读。

## 4. 从插值与拟合课学到的问题分析方法

### 4.1 先判断数据有没有噪声

杨雨茜老师讲插值与拟合时，把两者区别讲得很清楚：插值追求“点的精确”，要求函数严格通过所有数据点；拟合追求“趋势的最优”，承认数据有噪声，通过最小化误差来抓整体规律。

这对问题分析特别重要。

如果题目给的是精确节点、要求补全中间值，可以考虑插值；如果题目给的是观测数据、实验数据、历史数据，就不能轻易强行插值，而要考虑拟合或回归。

### 4.2 数据类问题要先问三个问题

```text
1. 数据点是否可信到必须全部穿过？
2. 数据是否含噪声或测量误差？
3. 题目要补点、还原趋势，还是预测未来？
```

例如：

- 缺失值补全：可能用线性插值、样条插值。
- 实验规律分析：更适合最小二乘拟合。
- 预测趋势：要考虑拟合误差、外推风险。

杨雨茜老师还讲到高次插值容易出现龙格现象，节点多反而可能端点振荡。这提醒我：问题分析时不能看到“离散点”就上高次多项式，要考虑稳定性和误差。

### 4.3 对论文表达的迁移

在论文里写数据建模时，要说明：

- 为什么用插值而不是拟合；
- 为什么用拟合而不是插值；
- 数据噪声如何处理；
- 误差指标如何计算；
- 是否存在外推风险。

这比单纯写“利用最小二乘法拟合”更有说服力。

## 5. 从决策模型课学到的问题分析方法

### 5.1 决策不等于优化

邹青松老师的决策模型课提醒我，决策问题要看信息条件：确定型、不确定型、风险型、多属性决策，它们的处理方式不同。

例如：

- 确定型决策：参数已知，可以直接比较成本或利润。
- 风险决策：概率已知或可估计，要比较期望收益、风险损失。
- 不确定型决策：概率未知，可能要用乐观、悲观、折中等准则。
- 多属性决策：方案有多个评价指标，需要权重和综合评价。

2024B 问题二接近风险决策，因为次品率给定，可以算期望利润；问题四则变成参数估计不确定下的决策修正。

### 5.2 决策问题要写清依据

张胜利老师讲问题二时也强调，要考虑决策依据，如期望成本、收益或利润，并确定详细决策指标。

所以问题分析中不能只说“制定决策方案”，要说清：

```text
我用什么指标判断方案好坏？
```

如果指标是期望利润，就要说明为什么它能综合成本、售价、调换损失和拆解费用。

## 6. 从智能优化课学到的问题分析方法

### 6.1 算法选型要看问题类型

张朝辉老师的智能优化课中给了算法选型思路：一次性优化、组合优化、序贯决策、多目标、多智能体，对应的方法不同。

我可以迁移成问题分析中的判断表：

| 问题特征 | 可能方法 | 分析重点 |
|---|---|---|
| 连续变量优化 | PSO、梯度法、非线性规划 | 变量范围、目标函数连续性 |
| 组合优化 | GA、SA、PSO、整数规划 | 编码方式、约束处理、搜索空间 |
| 路径规划 | 图算法、GA、SA | 节点、边、路径约束 |
| 动态决策 | Q-learning、动态规划 | 状态、动作、奖励、转移 |
| 多目标 | 多目标规划、NSGA-II | 权重、Pareto 解、冲突指标 |

### 6.2 不能为了高级而用高级算法

张朝辉老师也提醒，数模不需要高档方法，方法能结合问题稍加改进并解决问题就行。我的理解是：

```text
算法复杂度要服务题目，不服务炫技。
```

例如问题二变量少，用穷举法反而更可靠；问题三变量多，才有必要考虑粒子群、遗传算法等启发式方法。

## 7. 用 2024B 题综合练习问题分析

### 7.1 问题一：统计检验和最小样本量

问题一要求在信度要求下设计尽可能少的抽样方案。它不是普通计算，而是抽样统计问题。

分析重点：

- 样本中次品数是随机变量；
- 需要用抽样分布描述；
- 信度要求对应判决概率；
- “尽可能少”对应最小样本量；
- 输出应包括样本量和判决阈值。

可用方法：超几何分布、二项分布近似、正态近似。

### 7.2 问题二：0-1 决策和期望利润

问题二要求根据表 1 制定检测和拆解决策。

分析重点：

- 决策变量是“是否检测”“是否拆解”；
- 每个动作影响成本和收益；
- 评价标准应明确为期望成本、收益或利润；
- 变量少，可枚举全部策略；
- 要注意拆解后零配件是否需要重复检测。

这融合了最优化课的三要素和决策模型课的决策依据。

### 7.3 问题三：多工序组合优化

问题三扩展到多道工序、多个零配件和半成品。

分析重点：

- 决策变量维度增加；
- 生产结构可以用图或树辅助表达；
- 穷举法可能组合爆炸；
- 需要设计编码方式和目标函数；
- 可用粒子群、遗传算法、动态规划等方法。

这里可以吸收图上优化课和智能优化课的思想。

### 7.4 问题四：参数不确定性

问题四说明次品率来自抽样检测。

分析重点：

- 次品率不再是确定参数；
- 需要估计真实次品率区间；
- 抽样误差会影响期望利润和最优策略；
- 可以用置信区间、贝叶斯修正或模拟分析；
- 要比较修正前后的决策变化。

这也和插值拟合课中的“数据有噪声，要承认误差”思想一致。

## 8. 问题分析的深度检查：从“能用”到“该用”

这一章最容易写成方法清单：看到优化就写优化，看到数据就写拟合，看到复杂就写粒子群。但真正的问题分析不只是判断“能不能用某方法”，还要判断“该不该用”。

我现在给自己加一个二次诊断表：

| 候选方法 | 先问的问题 | 什么时候适合 | 什么时候该换方法 |
|---|---|---|---|
| 枚举搜索 | 方案数量有多大？ | 变量少、组合数可控、需要精确比较 | 组合爆炸，计算量无法说明 |
| 0-1整数规划 | 决策是否都是“选/不选”？ | 约束清楚、目标可写成成本或收益 | 约束太复杂，难以线性化或变量太多 |
| 图模型 | 对象之间是否有关系？ | 路径、连接、转移、装配、流量明显 | 只有独立指标，没有对象关系 |
| 插值 | 数据点是否可信且要补中间值？ | 节点较少、点较可靠、只在区间内补值 | 数据有噪声、需要预测趋势或外推 |
| 拟合/回归 | 是否要找趋势或预测？ | 数据含噪声、关注整体规律 | 样本太少或机制关系更重要 |
| 微分方程 | 是否有随时间演化的状态？ | 传播、增长、衰减、扩散过程明显 | 只有静态表格，没有动态机制 |
| 智能优化 | 是否高维、非线性、难精确求解？ | 编码清楚、适应度可计算、需近似搜索 | 小规模问题可精确求解，没必要上复杂算法 |
| 机器学习 | 是否有足够样本和特征？ | 预测目标明确、训练测试可分 | 样本少、解释性要求强、数据质量差 |

这个表的作用是逼我写出“为什么不用另一种方法”。比如 2024B 问题三可以用粒子群，不是因为粒子群高级，而是因为多工序0-1决策维度上升后，简单枚举可能组合爆炸；但如果我只做问题二的小规模场景，枚举反而更透明。

### 8.1 问题分析段落的写法

我现在不再把它叫“模板”，而叫“诊断顺序”。每一问按下面顺序想：

```text
任务本质 → 输入条件 → 可控变量 → 约束/误差 → 候选方法 → 为什么选它 → 输出结果
```

例如问题三可以写成：

```text
问题三的核心任务是在多工序生产结构中选择检测与拆解决策。输入条件包括各零配件、半成品和成品的质量参数及成本收益参数；可控变量是各环节是否检测、是否拆解等0-1决策；约束来自装配流程和不合格品处理规则。由于决策维度从基础流程扩展到多工序流程，直接枚举可能出现组合爆炸，因此可将全流程策略编码为0-1向量，以期望利润为评价指标，考虑采用粒子群算法搜索近似最优策略，并用小规模枚举对算法结果进行校验。
```

这段比“本文采用粒子群算法求解问题三”更有说服力，因为它交代了输入、变量、约束、方法选择理由和验证方式。

### 8.2 我最容易漏掉的三句话

写问题分析时，我最容易漏三类话：

- 为什么这个问题不是另一个类型？比如“这里不用插值而用拟合，因为观测数据存在噪声”。
- 为什么这个算法规模上合适？比如“问题二枚举可行，问题三需要搜索”。
- 结果准备用什么指标评价？比如“以期望利润而不是单纯成本作为决策依据”。

这三句话如果补上，问题分析就会从“报方法名”变成“解释选择”。
## 9. 本章自查清单

写完问题分析后，我要检查：

- 有没有判断每一问的问题类型？
- 有没有抓住核心矛盾？
- 有没有说明变量、参数、约束和评价指标？
- 有没有说明为什么选当前模型？
- 有没有比较备选方法？
- 有没有吸收专题课中的方法判断，而不是只套论文写作模板？
- 有没有把复杂关系转成图、表或流程图的意识？
- 数据类问题有没有区分插值、拟合、噪声和误差？
- 决策类问题有没有说明决策依据？

## 10. 本章总结

问题分析是最能体现“我有没有读懂题”的部分。

我现在的理解是：

```text
问题分析 = 题型判断 + 核心矛盾 + 方法选择理由
```

这一章不能只靠论文写作课，还要把各专题课学到的建模判断迁移进来。优化课帮我抓变量、约束和目标；图优化课帮我看对象关系；插值拟合课帮我判断数据噪声；决策课帮我明确决策依据；智能优化课帮我判断算法类型；2024B 讲评课则告诉我这些判断如何落到一道真实赛题中。
